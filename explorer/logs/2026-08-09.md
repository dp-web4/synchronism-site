came from reading an objective function, not prose. Prose-level audits keep re-finding the same
class of error because both the true and the false statement look identical in prose (`tanh(γ·ln(1+·))`
either way). The argument is only visible in code.

systematics the registered instrument fixed by fiat?* Nobody had marginalised M/L in the arm that
produces the site's most-cited galaxy number, even though that exact omission was diagnosed
yesterday for TEST-11 in the same codebase. Ran it.

**4. What would falsify the current research posture?**

The posture is "this framework over-refutes itself." It would be falsified if the headline kills
strengthened under proper marginalisation. They did not — but they also did not die. Refutation #1
survives at every literature-defensible corner. I set out expecting a retraction and got a
degradation, which is the honest outcome and worth stating as such: **the posture survived a test
that could have broken it in either direction.**

## What Did *Not* Happen (deliberately)

I did not run a density-space RAR BIC, even though the topic's mirror question invites it. SPARC
does not measure ρ; producing that number requires a vertical-structure estimator, and generating a
fourth unnamed-estimator result would reproduce the exact failure mode this session documents. That
the framework's own equation is *not computable on the dataset its refutations run on* turned out to
be the session's most structural result — the empirical record is shaped by data availability, not
by theory commitment.

# Topic: Knee inventory — in which sector, if any, has a measurement ever placed a system at x ~ 1?

## Question
The compander C = tanh(γ ln(1+x)) has three regimes: linear (x ≪ 1, C ≈ γx), the knee (x ~ 1), and
saturation (x ≫ 1, C → 1). Across every sector the framework has touched — galaxies (density-keyed and
acceleration-keyed), cosmology (C(ρ̄(a))), chemistry (γ from N_corr), superconductivity, consciousness
(C ≈ 0.5) — **where has data actually sampled the knee**, so that the tanh/Hill shape itself, rather than
its linear or saturated limit, has been tested? Produce a one-table inventory: sector, what x is, the
range of x the data span, which regime that is, and whether the shape was therefore tested.

## Context
Graduate-physics visitor persona, 2026-09-06, unanswered question 2: "Is there any regime, in any domain,
where a measurement has placed a system at x ~ 1 so that the tanh/Hill shape (rather than its linear or
saturated limit) has actually been tested? From what I read, no." The same persona noted that the γ
Calculator lets you reshape an S-curve "that has never been observed."

What is already known, scattered across pages and the archive:
- Density-keyed galaxies: SPARC median x ≈ 7×10⁻⁵, C = γx to 1.8% — pure linear regime (explorer 2026-09-03).
- Acceleration-keyed galaxies: x = g_bar/a₀ spans the RAR transition, i.e. the knee IS sampled — but there the
  function is MOND's μ_simple(x/2) at γ = ½, so what is tested is MOND's interpolating function, not a
  Synchronism shape (the form-selection table is a MOND-μ bake-off; free-γ vs Hill n=1 gap = ln N exactly).
- Cosmology: at γ = ½, C ≡ Ω_m(z) — the "knee" crossing is ΛCDM's matter–Λ equality, by identity.
- Chemistry: γ is fitted per material; what x is there, and whether any material sits at x ~ 1, is unclear.
- Consciousness: C ≈ 0.5 is the midpoint of a normalized range, not a measured x.

## Why It Matters
If the answer is "the knee has been sampled only where the function is provably someone else's (MOND's μ,
ΛCDM's Ω_m(z))," then the site can state plainly that **the tanh shape has never been tested as
Synchronism's**, which is stronger and clearer than "tanh carries no statistical content." It also settles
whether the Coherence Explorer and γ Calculator should say "this shape is decorative outside x ~ 1, and no
Synchronism-specific measurement has reached x ~ 1." If instead some sector does sample its own knee, that
is the one place a shape test could ever be run — worth knowing.

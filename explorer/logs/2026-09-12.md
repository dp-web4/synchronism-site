## Near-misses, caught inside the session

1. **A 34× artifact in the headline number.** The first B1 run gave a framework ceiling of
   Δf_DM = 3.2×10⁻¹ — which would have made TEST-20 *non*-discriminating and inverted the whole
   conclusion. It came from 152 points beyond R_HI where my gas model left ρ_bar = 0, letting the
   ambient term dominate. Fixed by differentiating SPARC's own V_gas for a local Σ_gas with a
   1.33 M☉/pc² floor inside R_HI; the ceiling dropped to 9.36×10⁻³ and a four-row floor-sensitivity
   table is now in the output. *The tell was `min rho_bar = 0.000e+00` printed two lines above.*
2. **A comparison that wasn't like-for-like.** I first put MOND's EFE at e_N = 0.30 (a rich cluster)
   against the framework at δ = 1000, and got 6.9×. Chae+2021's *measured* SPARC contrast is
   e_N ≃ 0 → 0.066. Re-anchored on the observed contrast for both sides; the ratio went to 255.5×,
   and the numbers are now comparable rather than each chosen at its own extreme.
3. **A χ² that pointed the other way.** The constant-boost-vs-MOND test gives aggregate χ²/N 99.8 vs
   51.8 (MOND wins) but **per-galaxy median 8.23 vs 10.54 (constant boost wins)** — the aggregate is
   carried by the best-measured discs. Reported both and leaned on the parameter-free RAR-slope test
   instead. A one-sided read of the aggregate would have been a clean over-refutation. *(This is the
   09-09 subsample lesson in a new costume: the statistic that decides has to be chosen before you
   see which way it points.)*
4. **My own WAKE hypothesis, corrected by its control** — see Key Finding 2. Published the weaker,
   truer version.

## Rabbit Holes (Worth Revisiting)

- **Chae+2021 is a dataset this site has not used.** Per-galaxy e_N for ~150 SPARC galaxies, located
  in the cosmic web — exactly the environment proxy the 2026-07-14 run built by hand from
  Cosmicflows-4, and exactly what 09-11's "B_req vs environment rank ρ = −0.31, candidate EFE lead"
  should be tested against. This is a concrete, free, runnable follow-up.
- **Is "predicted e_N" even well-posed for a law with no external field?** The framework's TEST-20
  prediction is naturally Δf_DM; Chae's estimator is e_N. My guess is the framework has no e_N at
  all, which would be a cleaner statement than the 256×.
- **TEST-15's kill criterion (10⁻¹⁶) is below the best bound ever achieved (10⁻¹⁵).** The site says
  so on `/falsifiability`. How many other kill criteria are written below instrument reach? That is
  a one-pass sweep of the registry's `kill:` fields and nobody has done it.

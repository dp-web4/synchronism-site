(e) THE VERTICAL TEST IS DIFFERENT -- and it is the one that is not a size test
================================================================================
  At fixed R in a disk, varying z:  rho(z) falls ~exponentially, but g_z RISES
  then saturates.  The system is not virialised in z, so rho/g is NOT fixed by
  a radius, and the identity above does not apply.  For a sech^2 disk of scale
  height h and midplane density rho0:
     rho(z) = rho0 sech^2(z/2h)      g_z(z) = 4 pi G rho0 * 2h tanh(z/2h)
     => rho/g_z = sech^2(z/2h) / (8 pi G h tanh(z/2h))    -- z-DEPENDENT

### What I Found

The framework presents C(ρ) = tanh(γ · log(ρ/ρ_crit + 1)) as its core equation. But it actually uses three different functions:

1. **Tanh-density** (site, equations.ts): C → 0 as ρ → 0, no floor, steep transition, EFE stronger than MOND
2. **Hill-acceleration** (research archive): C ≥ Ω_m ≈ 0.315, bounded, EFE ~0.3-0.4× MOND
3. **Empirical RAR** (galaxy rotation page): g_obs = g_bar / (1 − e^{−√(g_bar/a₀)}), not the C function at all

These make opposite predictions about the EFE, which is the framework's most distinctive testable claim. The site never mentions this ambiguity. The honest assessment — otherwise exemplary — is silent on the formulation question.

The researcher's question "Is there any prediction that differs from MOND?" cannot be definitively answered because the answer depends on which C you use.

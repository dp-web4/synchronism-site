## The Problem

The framework claims TEST-02 (Gaia DR3 wide binary anomaly) is a discriminating prediction:
Synchronism predicts the wide binary MOND anomaly is **stronger in denser stellar fields**,
while standard MOND predicts it is **density-independent**.

This is a genuine novel prediction. But it is currently **unfalsifiable** because no functional
form ξ(ρ) has been specified for the density dependence.

The Chae (2023) vs Banik et al. (2024) disagreement on Gaia DR3 is ongoing. More Gaia analyses
are coming. If no ξ(ρ) is published before those analyses, *any* non-uniform result can be
claimed as confirmation post-hoc. This destroys the prediction's scientific value.

## The Task

Derive or specify ξ(ρ) for the wide binary anomaly from within the Synchronism framework.

Specifically: if the framework predicts the wide binary anomaly scales as g_obs/g_Newt ~ 1 + ξ(ρ),
what is ξ as a function of local stellar density ρ_*?

Candidate approaches:

1. **From C(ρ) directly**: The coherence function at the density of a wide binary pair's stellar
   neighborhood should predict the effective gravitational coupling. What does C(ρ_stellar) predict
   for the EFE amplitude?

2. **From the MOND interpolating function**: The site already notes that a₀ = cH₀/(2π) is
   Synchronism's interpretation of a₀. If the coherence function modifies the local effective a₀,
   the density dependence follows from how C(ρ_local) modifies a₀_local.

3. **From the RAR scatter ansatz**: The environment-dependent RAR scatter (TEST-03) was specified
   as σ_int(ρ_env). The wide binary prediction may be the same physics at a different scale.
   Can TEST-02 and TEST-03 be unified into a single ξ(ρ) expression?

## What Would Count as Success

A specific ξ(ρ) that:
- Predicts a measurable difference between wide binaries in dense stellar fields (globular cluster
  outskirts, galactic midplane) vs sparse fields (halo, void)
- Has a kill criterion: "ξ(ρ) predicts X% enhancement in field A vs field B; null result within
  Y% falsifies the density dependence"
- Can be written down before the next Gaia wide-binary analysis is published

## Why This Is Urgent

Without ξ(ρ), TEST-02 is a fishing license not a prediction. The Chae/Banik controversy will
likely be resolved in the next 12-18 months. If it resolves as "density-dependent anomaly, as
Synchronism predicted" WITHOUT a prior specification of ξ(ρ), the claim cannot be counted as
a framework success — it will be correctly classified as post-hoc.

This is the most time-sensitive open gap in the framework's test portfolio.

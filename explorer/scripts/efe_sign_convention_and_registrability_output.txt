------------------------------------------------------------------------------
PART A2 - the axis that DOES determine the EFE: what C's argument is
------------------------------------------------------------------------------

  Source-side arguments (functionals of the matter distribution only):
    C(rho)    : uniform g_ext leaves rho unchanged            -> EFE = 0 exactly
    C(g_bar)  : g_bar is Newtonian-Poisson from rho; the
                external mass is not internal baryons         -> EFE = 0 exactly

  Solution-side argument (a functional of the field being solved for):
    C(|grad Phi|) : |grad Phi| = |g_int + g_ext| includes the external field.
                    This IS AQUAL with nu = 1/C.  Bekenstein-Milgrom 1984 derive
                    the EFE from exactly this.  EFE != 0, MOND-sized, suppressing.

  Numerically, algebraic MOND-with-EFE, g_obs*(g_obs + g_ext) = g_bar*a0:
    e =  0.00  ->  g_obs/g_iso = 1.0000   Delta log10 = +0.0000 dex
    e =  0.03  ->  g_obs/g_iso = 0.9837   Delta log10 = -0.0071 dex
    e =  0.05  ->  g_obs/g_iso = 0.9730   Delta log10 = -0.0119 dex
    e =  0.15  ->  g_obs/g_iso = 0.9212   Delta log10 = -0.0356 dex
    e =  0.50  ->  g_obs/g_iso = 0.7630   Delta log10 = -0.1175 dex

  -> EFE is set by the ARGUMENT fork (rho / g_bar / |grad Phi|), not by the
     FORCE-LAW fork (amplitude / division / multiplication).  The two forks are
     orthogonal.  Under both source-side arguments EFE = 0; under the solution-side
     argument the framework IS MOND and has MOND's EFE.  No branch gives a nonzero
     EFE of framework-specific sign.

               1e+06    9.9997e-01    1.0000e-10    9.9997e-11    165.9510

  L1 (division)       : g_obs DECREASES  (3.265e-06 -> 1.000e-10)  = velocity DEFICIT   [same sign as MOND's EFE]
  L3 (multiplication) : g_obs INCREASES  (3.063e-15 -> 1.000e-10)  = velocity SURPLUS   [opposite sign]
  L2 (amplitude)      : v INCREASES      (71.000 -> 165.951)  = velocity SURPLUS   [opposite sign]

  -> The 2026-08-04 'the two conventions give opposite-signed environmental effects'
     is CORRECT, and it is a statement about the rho_ext channel.  It says nothing
     about the EFE, which is the g_ext channel and is zero in every reading.

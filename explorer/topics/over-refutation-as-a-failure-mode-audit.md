# Topic: Audit the refutations the way we audit the claims

## Question
Two of today's four visitor personas independently found **errors in the site's own demotions**:

1. `/consciousness-demo` argued C = 0.50 is not dynamically privileged because "dC/dρ is maximised
   at ρ = 0." True in linear ρ, false in log ρ — and at γ = ½ the log-density inflection is
   **exactly 0.500**. The conclusion (circularity) stands; the argument was false.
2. `/galaxy-rotation` called the compander's power-law tail "the framework's one genuinely
   non-MOND-degenerate piece of physics," while simultaneously (and correctly) stating that at
   γ = ½ the compander *is* Milgrom's simple μ identically. The power-law tail is Milgrom's.

Both errors point **against** the framework, which is why they survived — the audit machinery is
tuned to catch overclaiming and does not symmetrically catch over-refuting.

**The question: how many more are there?** Run the same adversarial pass over the *refutation*
column that has been run over the claim column. Every σ, every ΔBIC, every "no", re-derived.

## Context
Visitor researcher, 2026-09-07: "This project's characteristic failure mode is no longer
overclaiming — it is **overclaiming its own refutations**, with the same lack of error bars, and the
cure is identical." Both errors were fixed on the site the same day and back-annotated; this topic
is about whether they are a pattern.

## Why It Matters
Known instances of over-refutation already on record: the a₀ "8σ" (systematics vs random), the
ΔBIC = +184 effective-N inflation, the +17.95σ vs published 8.7σ Cassini gap, the dark-energy
"3.4–6.3σ excluded" figures that did not survive direct fit, the J = 0 point estimate on n = 6, and
now these two. That is **seven**. Seven is not a run of bad luck; it is a systematic bias in one
direction, and it is the direction a self-auditing program is structurally blind to.

The credibility argument is symmetric and the site should say so: a reader who checks a refutation
and finds it wrong discounts the honest ones too. Over-refuting costs exactly what overclaiming
costs — and unlike overclaiming, nobody external is motivated to catch it.

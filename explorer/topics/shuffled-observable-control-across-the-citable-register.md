# Topic: Run a shuffled-observable control on every σ in the citable register and Bucket 2

## Question
For each negative result the site prints with a σ, Δχ², ΔBIC or Δr, does the number move when the observation is
permuted (or replaced by a synthetic draw from the null)? Which rows are data-facing, which are model separations, and
which have never been checked?

## Context
On 2026-10-30 the maintainer published "EFE-free corner closed, 10.6σ". It was a paired difference of residuals, so the
observation cancelled (your finding the same day). On 2026-10-31 a visitor persona found that the chemistry
polynomial-in-Z null, quoted on 11 site files since May, was run on synthetic curves and never on the rows. Both
errors made the framework look worse than the data show. The maintainer proposed a data-dependence column
(`Synchronism/Research/proposals/refutation_statistics_need_a_data_dependence_column_20261031.md`).

## Why It Matters
The register is only citable if each row's number is about the data. A table where most rows *survive* the control
is citable in both directions. Expected outcome: most rows pass (SPARC galaxy-level ΔBIC is a loss, so it is safe). The
interesting rows are the ones that do not.

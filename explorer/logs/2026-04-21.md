## Key Findings

- **`pci-kill-criterion-already-passed.md`** — Casarotto 2016 demonstrated a sharp
  consciousness threshold (PCI\* = 0.31) with 100% sensitivity and specificity on ROC
  analysis across 150 benchmark subjects + 81 DOC patients. This satisfies every criterion
  in Synchronism's stated kill test ("sharp discontinuity at specific value, consistent
  across subjects"). Striking observation: PCI median for *awake controls* is 0.53 —
  almost exactly Synchronism's claimed "threshold." If C correlates with complexity/
  integration measures (as the framework implies), then C = 0.50 describes ordinary
  wakefulness, not the transition. The real empirical threshold is 0.31. The claim thus
  collapses into four disjoint outcomes: (A) rescaling of PCI → Reparametrization badge,
  (B) C = PCI in same units → 0.50 is falsified, threshold is 0.31, (C) C ≠ PCI with
  specified divergence → genuinely novel/testable but currently undefined, (D) C shows
  no sharp transition while PCI does → worst outcome. Currently the site occupies none
  of these positions because it has not engaged PCI at all.

  Concrete maintainer recommendation: add a "Relation to the Perturbational Complexity
  Index" section to `/consciousness-threshold` committing to (A), (B), (C), or an
  explicit deferral. Retag prediction to "Untested, not-yet-operationalized" with a
  note that the sharp-transition criterion has already been independently established
  at a threshold that differs from 0.50.

## So what?

Does this advance discovery or just document the current state?

This session moves the discovery needle in a specific way that builds directly on the
prior three consciousness findings. Those three findings each independently asked the
same unresolved question — *if C were operationalized from neural data, what value would
the transition occur at?* — and none had an external empirical anchor to answer it. Today's
finding supplies that anchor: PCI\* = 0.31, with 100% sensitivity and specificity on
ROC analysis, across a large validated sample. That single number converts a persistent
internal critique into a concrete external-literature comparison with decisive
implications. The Synchronism claim C ≈ 0.50 is now either a rescaling of PCI (benign
reparametrization), a falsified value if C correlates with PCI (0.50 is in fact the
awake-control median, not the transition), or a genuinely novel claim about a
differently-operationalized measure — but the site must commit to one of these, which
it currently does not.

Secondarily, this finding crystallizes a pattern Pass 4 half-named and extends yesterday's
"target reinterpretation" antipattern: **literature-blind claim staking**. The
consciousness claim, the quantum measurement page, the wide-binary test, and the
resynchronization claim all share the shape of "we propose a test" without engaging the
most mature competing empirical framework in the domain. Four instances is enough to
warrant a dedicated methodology section on `/research-philosophy` — the second of two
named antipatterns in two days, both derivable from a process that stress-tests internal
coherence but not external contact. If the A2ACW methodology is insular by construction,
*naming* that insularity is the fix, not patching individual claims.

The most interesting secondary finding — PCI median of 0.53 for awake controls being
almost exactly Synchronism's "threshold" of 0.50 — is the empirical realization of the
prior artifact analysis' warning. "0.50 is suspicious because it is the midpoint of
[0,1]" is now "0.50 is suspicious because it is the median of normal waking PCI, not
of the transition." This crisply falsifies the specific value 0.50 *if* C is defined
to be complexity-like in the PCI sense; it tightens the claim *if* C is defined to be
something else, by forcing that choice. Either way, discovery is advanced — and the
choice of which way is on the framework, not the explorer.

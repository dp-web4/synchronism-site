# Topic: Is C(ρ) Untestable With Foreseeable Data?

**Priority**: HIGH
**Seeded**: 2026-06-23 (maintainer track, from Pass 4 researcher feedback)
**Status**: Open

---

## The Question

The site says "0 confirmed predictions, 0 discriminating tests vs MOND+EFE+ΛCDM." Pass 4 raises a sharper question:

> "Is there any live measurement under which C(ρ) and MOND+EFE+ΛCDM diverge by more than the current systematics floor? If not, the framework is not merely unconfirmed — it's **untestable with foreseeable data**."

These are different things. "0 confirmed" implies testability is intact. "Untestable with foreseeable data" says no reachable measurement can decide the question — the signal is structurally below any reachable systematics floor.

---

## What To Do

Run through the full test catalog (TEST-01 through TEST-21). For each surviving, non-withdrawn test:

1. What is the C(ρ)-specific predicted signal amplitude? (Must differ from MOND+EFE prediction in direction or amplitude above systematics floor)
2. What is the current systematics floor of the relevant instrument/dataset?
3. Signal-to-systematics ratio: above or below 1?

The existing evidence:
- TEST-01/05: ~120× below SPARC reach, MOND+EFE-degenerate in direction
- TEST-02: 0.05–0.4% predicted deviation; Gaia DR3 systematics ~3–5% for clean wide-binary samples → ~80× below reach; no outcome selects Synchronism over Newton/MOND
- TEST-04a: failed by sign (suppression predicted, enhancement observed)
- TEST-03: kill criterion triggered
- TEST-09/10: MOND-shared, cannot discriminate
- Clusters: structurally silent (ρ_crit 10⁴–10⁶× off)

---

## The Deliverable

If all signal-to-systematics ratios are below 1 (or the test is MOND+EFE degenerate above the floor), the thesis is confirmed. The publishable statement would be:

> "C(ρ), as currently formulated, makes no prediction distinguishable from MOND+EFE+ΛCDM above the systematics floor of current-generation instruments. The framework is not merely unconfirmed — it is untestable with foreseeable data."

This is a citable null result — stronger and more precise than "0 confirmed predictions," and more useful to the literature.

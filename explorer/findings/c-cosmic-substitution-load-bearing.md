## 1. Reproduction

`Synchronism/simulations/session107_desi_forecasts.py` defines:

```python
def C_galactic(z, rho_ratio=1.0, gamma=2.0):
    rho_eff = rho_ratio * (1 + z)**3
    return np.tanh(gamma * np.log(rho_eff + 1))

def C_cosmic(z):
    """Cosmic coherence derived in Session #101.
       C_cosmic = Omega_m(z) = matter fraction at redshift z."""
    return Omega_m * (1+z)**3 / (Omega_m * (1+z)**3 + Omega_Lambda)
```

with `ratio_0` calibrated so `C_galactic(z=0) = Omega_m = 0.315`. This anchors
the two functions to agree at z = 0; the prediction is then driven entirely by
their different rates of approach to unity at higher z.

Running the published growth integration with these definitions:

```

At z = 0.51:

  Published: ~0.418  --  reproduction error: -0.0001
```

The 0.418 number is recovered to four decimal places. The growth integration
is correct as published.

## 6. Why the Mechanism Is Not the Coherence Equation

Take Session 107 seriously as a derivation. What is it saying physically?

It posits a modified Poisson equation `∇^2 phi = 4πG * G_rat * rho`, where
`G_rat = C_cosmic / C_galactic`. Setting aside the mechanism's other problems
(it pre-dates DESI DR1 by 8 months but commits the calculation 8 months *after*
DR1, raising the post-hoc issue separately flagged), the *suppression sign*
requires `C_cosmic / C_galactic < 1` during structure formation.

For this to be a coherence-physics statement, both C's must be values of the
same function on the same physical scale. Session 107 instead uses two
different functions of the same scaled density:

* C_galactic = `tanh(2 ln(0.177 * (1+z)^3 + 1))`
* C_cosmic = `Omega_m * (1+z)^3 / (Omega_m * (1+z)^3 + Omega_Lambda)`

The first saturates to 1 as `2 ln(x)` — fast. The second saturates to 1 as
`1 - O(1/(1+z)^3)` — slower. The gap between them grows with z, then closes
again as the second approaches 1 in matter domination.

This is not a two-scale coherence comparison. It is a comparison of how
*differently shaped sigmoids of the same density variable* approach saturation.
The mechanism would more honestly be stated as: *"the LCDM matter fraction
Omega_m(z) is faster to saturate than tanh(2 ln(0.177(1+z)^3 + 1)); we treat
this gap as a real growth-suppression factor."* Stated that way, the gap is
parameterized by exactly one free choice (ratio_0 = 0.177) and has no further
predictive structure beyond what fitting two sigmoids to agree at z=0 produces.

# Topic: MRH-Crossing vs. Zurek Einselection — One Discriminating Prediction

## Question

Is there a single experimental scenario where MRH-boundary-crossing predicts a different outcome than Zurek einselection (pointer-state predictability sieve)? If not, the framework's measurement theory should be re-badged as Reparametrization.

## Why It Matters

- If MRH-crossing IS einselection in new notation, re-badging as Reparametrization is the honest thing to do — and surfaces the framework's genuine novelty more clearly
- If MRH-crossing makes a genuinely different prediction (e.g., a system where the MRH contracts non-continuously while Zurek predicts smooth decoherence), that's a paper-worthy discriminator
- The site currently claims "dissolution of the measurement problem" — this is either one of the framework's strongest contributions or its most overclaimed section, and this question determines which

## Specific Questions to Resolve

1. For a system crossing MRH: does Synchronism predict a discrete (first-order) decoherence event or continuous? Zurek predicts continuous.
2. Does γ collapsing when N_corr explodes give a *different decoherence timescale* than the Caldeira-Leggett master equation timescale τ_dec ~ ℏ²/(λ²mkT·Δx²)? If so, specify the difference.
3. Is there a system size where MRH gives a different pointer basis than Zurek's predictability sieve? (i.e., a case where Synchronism selects different pointer states?)

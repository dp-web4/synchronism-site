## Key Findings

### 1. `information-geometry-log-density-derivation.md`
**The log-density argument is the log-partition function of a binary exponential family.**

The argument log(ρ/ρ_crit + 1) inside the coherence function equals softplus(log(ρ/ρ_crit)) = log(1 + e^ξ), which is the log-partition function A(ξ) of the Bernoulli exponential family evaluated at the log-density-ratio ξ = log(ρ/ρ_crit).

This means:
- The "+1" is not ad hoc regularization — it's the reference state in Z = 1 + e^ξ
- The full function C = tanh(γ · A(ξ)) is a canonical composition of two exponential family operations
- The derivation status of log(ρ/ρ_crit + 1) upgrades from "modeled" to "derived within exponential family theory"
- Only γ and ρ_crit remain as non-derived inputs (dimensional analysis + empirical)

The function's status upgrades from "parametric ansatz with theorem-derived kernel" to "canonical information-geometric map between density and coherence manifolds."

### 2. `efe-interpolation-function-comparison.md`
**The prior EFE analysis was wrong. Sync predicts stronger EFE, not weaker.**

The theoretical-status-synthesis concluded bounded C predicts weaker EFE because C ≥ Ω_m ≈ 0.315. This was a category error — it applied the cosmological C (with Ω_m floor) to galactic scales, where the operative form C → 0 as ρ → 0 (no floor).

Numerical comparison of interpolation functions reveals the Sync function tanh(2·log(x+1)) is MUCH steeper than all MOND interpolation functions:
- At x = 1 (a = a₀): Sync is 88% Newtonian, MOND simple is 50%, RAR is 63%
- By x = 2: Sync is essentially Newtonian (97.6%); MOND still has significant modification

This means the EFE is STRONGER under Synchronism — a moderate external field nearly completely restores Newtonian dynamics. Testable prediction: dwarf satellite galaxies in moderate external fields should be nearly Newtonian under Sync but still significantly modified under MOND.

The steeper transition also raises a potential empirical problem: does the Sync interpolation match the empirical RAR shape?

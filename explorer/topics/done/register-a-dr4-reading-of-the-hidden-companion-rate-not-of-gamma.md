# Topic: Register a DR4 reading of the hidden-companion rate itself, not of γ

## Question
Before Gaia DR4 (2 December 2026), can the per-star close-companion rate of the wide-binary samples be written as a quantity
DR4 measures directly, with a reading rule dated before the data: which DR4 products (epoch astrometry, RUWE time series,
RV-variability flags), which sample, and which value separates "Newton explains the near-escape systems" (≈ 0.45–0.5) from
"it does not" (≈ 0.3)?

## Context
Explorer 11-09 found that the wide-binary dispute turns on one measurable number. At a per-star rate of 0.3 only ~7% of the
36-system sample is contaminated, yet the boost estimate moves 1.87 → ~1.2. Newton needs 0.45–0.5, the field value for
solar-type stars (Moe & Di Stefano 2017) but 3–5× what the 2D parent implies under Chae's eccentricity prior. A researcher
visitor persona (2026-11-17) called this "the most externally useful number on the site" and asked whether anyone outside has
seen it. The site's existing DR4 key maps a boost to γ, which every outcome lands on an excluded member, so it cannot inform
anyone. A companion-rate reading could inform both sides of a live dispute that has nothing to do with this framework.

## Why It Matters
This is the first prospective test the program could run whose answer someone outside would use. It is also the concrete
first step of the 2026-11-17 proposal ("the external value has moved"), whose direction question gates on the project lead.
If it turns out that DR4 cannot measure the rate at the needed precision, that is worth knowing before 2 December too.

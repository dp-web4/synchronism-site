## Pass 1: Casual Science Enthusiast

### Summary
- **Pages visited**: 12 (landing, Why Synchronism?, First Encounter, Core Idea, What Synchronism Is Not, Honest Assessment (top), Interactive Tools, Coherence Explorer, Galaxy Curve Plotter, γ Calculator, Glossary, Learning Paths)

- **Would return?**: maybe
- **Overall impression**: The crowd-vs-marching-band idea landed in about a minute, and then every single page spent the next ten minutes telling me it didn't work, in language I mostly couldn't follow.

### Journey

Came in from a Reddit link. The first line, "What if one equation described reality from quantum to cosmic?", is exactly the hook I'd click on. The very next three lines say "We proposed this. We tested it. It did not hold as stated." Honestly that was a bit of a gut-punch, but also kind of refreshing — I've read enough "new theory of everything" pages to be suspicious, and this one leads with its own failure. I kept scrolling. There's a big equation with "tanh" in it (no idea, skipped) and then a bunch of numbers — 3,308 sessions, 14,610 galaxies, 1,703 chemical phenomena, 0 confirmed predictions. The zero is what I noticed. Then a table of three claims where every row says Speculative or Failed. At this point I wasn't sure why I was still reading, but there was a "Beginner Path →" button so I clicked it.

**Why Synchronism? (Step 1).** This page is good at the top. "A crowd milling around a plaza behaves like independent individuals; a marching band behaves like one organism" — I got that instantly, and the "dimmer switch" picture too. There's an explicit "you can stop here and go to Step 2" note, which I appreciated, because below it the page turns into a wall. I skimmed anyway and hit "sign-inverted for all collective systems," "audited-negative," "phenomenological," "compander," "ansatz," "Hamiltonian," "Abrikosov–Gor'kov." Some of these have little plain-English glosses in parentheses, which helped, but there are so many that the glosses themselves became a wall. The MOND one-liner ("a 1983 rival idea that explains fast-spinning galaxy edges by tweaking gravity itself instead of adding invisible dark matter") was genuinely the clearest sentence on the page and I wish it had come earlier — MOND is mentioned on the landing page before it's explained anywhere.

**First Encounter (Step 2).** Seven short sections with a Continue button — I liked the pacing. Section A introduced "Markov Relevancy Horizon (MRH)" as "the minimal set of degrees of freedom whose transitions materially influence coherence." That's the formal definition offered to someone with no prior knowledge on the page that says it requires no prior knowledge. The "bubble of nearest neighbors" phrase right before it was enough; the formal one just made me feel like I'd missed a page. Section C says the γ thing "Failed in testing" and mentions "sign inversion (predicted +0.55, measured −0.55)" — I understood that the number came out backwards, which is a nice concrete way to say "wrong." Section F (wave function collapse as a "whisper in a loud room") was the most interesting idea on the whole site for me and it's three sentences long. Section G lists error rates. So by the end of Step 2 I'd been told the framework failed about six times.

**Core Idea (Step 3).** This is where I bounced, mentally. The "plain words" box at the top was fine, but then: "ΔBIC +2843," "Hill coefficient," "Hill index n = 2γ," "log-log slope," "Landau theory," "critical exponents (β, ν)," "universality classes," "variational principle," "μ-law encoders," an exact identity with (1+x)^(2γ) in it. Also a lot of dated parenthetical notes — "(corrected 2026-07-27)," "(Flagged 2026-09-18 when a visitor noted...)," "(Until 2026-09-15 this section called...)" — which read like a changelog pasted into the article. I don't know what those are for. As a reader I don't need to know when a sentence was fixed; I need the fixed sentence. It's labelled "~12 min" on the Learning Paths page; it took me longer and I skipped most of it.

**What Synchronism Is Not (Step 4).** Short, clear, best page in the path. The bullet list ("Not proven, Not journal-reviewed, Not a replacement for existing physics, Not just philosophy") is exactly the level I wanted. "54 of 92 listed predictions (59%) were untested" — I could follow that.

**Honest Assessment (Step 5).** The "If you read nothing else" box up top is excellent and I read it. Then I saw it's listed as ~18,000 words with 27 more sections and I closed it. The path says "~4 min for summary; optional full 80-min read," which is honest, but 80 minutes of a beginner path is a lot.

**Tools.** The Interactive Tools page says "start with Coherence Explorer → Galaxy Plotter → Honest Assessment," so I did that.

**Glossary.** Looked up "Coherence" and "MOND" and "Dark matter." Definitions are one line each and readable. 98 terms, alphabetical, no search box — I had to scroll for M.

### Tools Tested

### Unanswered Questions

### Verdict
The pitch works and the honesty is unusual enough that I trusted the site more than most. But the beginner path doesn't stay beginner: Steps 1 and 2 hold the line for a few paragraphs, then Step 3 drops me into ΔBIC and Hill coefficients with no fold, and Step 5 is an 18,000-word page. I left understanding the crowd-vs-band picture, that it lost to something called MOND, and that the "whisper in a loud room" idea exists. I'd come back if there were a page that told me, in a few hundred words, what a curious non-physicist should take away from a well-documented failure.

## Pass 2: Technical Writer

### Summary
- **Pages visited**: 15 (landing, Why Synchronism?, Learning Paths, Glossary, Interactive Tools, Honest Assessment, Key Claims, MRH, Tier 1: Existing Data, Test Roadmap, Decisive Tests: Status, For Researchers, Equation Anatomy, Crossover Regime Visualizer, Consciousness Threshold Demo)
- **Understanding achieved**: good (of the structure; I did not evaluate the physics)
- **Would return?**: yes — as a reference for how a research site documents its own failures, less so as a reader
- **Overall impression**: The information architecture is unusually well-labelled — badges have a canonical definition page, anchors resolve, path pages carry step indicators — but the site keeps three different counts of the same tests and pastes its changelog into the body copy.

### Journey

I started at the landing page and did what I always do first: harvested every nav link and every acronym. The header has nine items. The labels and the URLs disagree twice: "Tools" goes to `/interactive-tools` (fine, the page is titled Interactive Tools) and "Test Roadmap" goes to `/test-catalog`, and the page it lands on calls itself "Test Roadmap" in the heading but "the 24-test catalog" and "Full Catalog" in its own body and in cross-links. One thing, three names. The landing page also lists its badges up front ("Badges used below: Reparametrization · Speculative · Untested · Failed · Audited-Negative") with a link to the canonical definitions on Honest Assessment. I checked that the anchor exists in the served HTML. It does, as do the "if you read nothing else" and "what was tested" anchors. That is better than most documentation sites manage.

Acronyms on the landing page: MOND, MRH, A2ACW and BAO are expanded at first use. CFD, ALFALFA, SDSS, DESI and fσ₈ are not, and SPARC is expanded only in a footnote. The Tier 1 page, by contrast, has a dedicated "Acronym key" section that expands MOND, RAR, BTFR, EFE, DESI, SPARC and DM cleanly. The glossary intro says some pages use a dotted-underline hover for terms. So the machinery for first-use definitions exists in two forms; it just isn't applied on the landing page, Key Claims (SPARC unexpanded), MRH (BTFR, RAR, SPARC unexpanded) or Why Synchronism (SPARC, ALFALFA, SDSS, YBCO unexpanded).

Learning Paths is the clearest page on the site. Three difficulty paths, four topic tracks, time estimates, and a note of which pages appear in multiple paths. I followed the Beginner path's step indicators and they are consistent: Why Synchronism? says "Step 1 of 6", Honest Assessment says "Beginner Path Step 5 of 6" and also "Methodology Track Step 6 of 6", Glossary says "Step 6 of 6" with a "Prev: Honest Assessment" link. MRH says "Physics Track Step 2 of 7" with prev/next to Coherence Function and Measurement Without Observers, matching the path listing. Nothing broken.

Breadcrumbs are inconsistent in depth. MRH is "Home / Core Theory / MRH", Tier 1 is "Home / Predictions & Experiments / Tier 1", For Researchers is "Home / Methodology / For Researchers". But Key Claims, Glossary, Honest Assessment, Why Synchronism and Learning Paths are just "Home / Page". The middle-level sections (Core Theory, Predictions & Experiments, Methodology) never appear in the header nav, so I could not tell whether they are real hub pages or just labels.

Then I did the count check, which is where the site loses points. The Test Roadmap says "26 tests (24 in the original registry + 2 added later)" and I confirmed TEST-01 through TEST-26 are listed. Its own "Overview by Tier" section says Tier 1: 10 tests, Tier 2: 4, Tier 3: 7, Tier 4: 3. That sums to 24, so the two added tests (TEST-25, TEST-26) are not in any tier total. The Tier 1 page then says it holds "11 numbered tests (TEST-01 through TEST-10, plus TEST-25), plus two variants" and displays 14 cards including an unnumbered CLUSTER-SCALE entry. So Tier 1 is 10, 11, or 14 depending on which page you read. The Learning Paths page says "Test Roadmap (26 tests)". The Decisive Tests page says "the 24-test catalog". The Tier 1 page even carries a note that a count "drifted when the Cassini squeeze was added" and was corrected on 2026-08-08, so the site knows this class of bug and it has recurred in the tier overview.

Same pattern on the Decisive Tests page: the body says "Two closed predictions remain below", and the "Closed predictions" section lists four (TEST-02, TEST-11, TEST-04a, TEST-04). Reading closely, the sentence describes two specific ones and then two more were demoted onto the list later, but the count phrase was never updated.

A third count-shaped inconsistency: the landing page says "the one non-degenerate galaxy test collapsed it onto MOND". For Researchers says "2 executed tests that discriminated, both selected MOND". Decisive Tests says "TEST-09/10 ... ran and selected MOND". A non-physicist cannot tell whether one or two tests did the collapsing, or whether "non-degenerate" and "discriminated" are the same property.

The badge taxonomy. The canonical section on Honest Assessment lists 9 formal badges (5 MRH-relationship, 4 descriptive), 2 deprecated labels, 9 "operational states" (Kill Criterion Triggered, Withdrawn, Artifact Lesson, Template Bias Caveat...) and 10 "status lifecycle verbs" (EXECUTED, ADJUDICATED, NEVER RUN AS REGISTERED...). That is about 30 labels across four categories. The Interactive Tools page then introduces a separate three-slot scheme per card (Kind / Level / Status) and says Status is "deliberately styled so it cannot be mistaken for a difficulty", but the cards also carry the claim badges (Failed, Reparametrization, Audited-Negative, Speculative), which is a fourth label type the intro does not mention. The glossary says nine badges are marked "(badge)" and I verified exactly nine entries carry that marker, so the glossary is internally consistent. The problem is not any one page; it is that a new reader has no single table saying "here are the four kinds of label, here is how to tell them apart visually".

Badge pills also mix categories inside one pill on Why Synchronism: "Failed | TEST-03/05 Environment Run — Refuted by Execution" and "89% Boundary-Consistent | Template Bias Caveat". The landing page's rule is "text after a dash inside a badge is a finding descriptor, not a separate badge". These pills use a pipe, and the second one has no formal badge in it at all (both halves are operational states). None of the pills on Why Synchronism or For Researchers link to the definitions, whereas the Equation Anatomy badge has a hover title and an "opens badge definitions" affordance. Good pattern, applied unevenly.

Revision notes. Pass 1 flagged these as reader friction; from a documentation standpoint the bigger issue is that they follow at least six formats on the pages I read: "(corrected 2026-07-17)", "Reframed 2026-07-23:", "Corrected 2026-09-21: this previously said...", "(added 2026-09-24)", "(stated 2026-09-10)", and "DRAFTED 2026-08-10 — HARDENED TO MODEL CLASS 2026-08-11". Key Claims alone has ten dated notes spanning February to September. Some are useful audit trail ("entered during editorial work with no source in any repository" on the Consciousness demo is exactly what a reader should be able to find). But they belong in a per-page revision history disclosure with one format, not inline.

The footer is the same on every page and contains its own changelog ("recounted 2026-07-30, roots split 2026-09-05"). It also introduces the term "roots" ("6 refutations from 5 roots") and links the word to Tier 1. I read Tier 1 looking for a definition of "root". There isn't one. The glossary doesn't have one either. It is the only term in the footer that is not defined anywhere I could find.

### Tools Tested
- **Equation Anatomy** (`/equation-walkthrough`) — worked — intuitive — A six-step "Previous / Next" walkthrough, no sliders. Every symbol (C(ρ), ρ, ρcrit, γ, ln, tanh, Ncorr) is defined in the step where it first appears, which is exactly right. ### Unanswered Questions
1. What is a "root" in "6 refutations from 5 roots"? The word is in the footer of every page and defined nowhere I could find.
2. Is Tier 1 ten tests, eleven, or fourteen cards? Which count should a citing reader use?
3. Did one test or two "select MOND"? Are "non-degenerate" (landing) and "discriminated" (For Researchers) the same property?
4. Are "Core Theory", "Predictions & Experiments" and "Methodology" real sections with hub pages, or breadcrumb labels only?
5. Which of the four label categories (badge / deprecated / operational state / lifecycle verb) is a reader supposed to treat as a verdict? ### Verdict
Structurally this is a well-built documentation site: paths have step indicators, badges have a canonical definitions page whose anchors actually resolve, and the glossary's badge markers match the stated count. The defects are the ones that come from hand-maintained numbers and hand-formatted notes: tier totals that don't sum to the headline count, a "two" that sits above a list of four, one-vs-two discriminating tests, and a changelog spread through the prose in six formats. Fix the counts by deriving them from one list, and give the revision notes one home and one format, and the site would read as carefully as it was evidently written.

## Pass 3: Graduate Physics Student

### Summary
- **Pages visited**: 16 (landing, Coherence Function, Core Idea, Parameter Derivations, γ Parameter, Phase Transitions, MRH, MOND Unification, Galaxy Rotation, Dark Matter Failure, Key Claims, Honest Assessment, Tier 1: Existing Data, Coherence Explorer, Galaxy Curve Plotter, γ Calculator)
- **Understanding achieved**: solid
- **Would return?**: maybe — as a case study in self-refutation, not for the physics
- **Overall impression**: The algebra is right and the site has already written most of my referee report for me; what's left to catch is that its own two conventions for the effective number of SPARC points put the γ=2 kill on opposite sides of its own decision threshold.

### Journey

A colleague sent this as "an interesting AI project," so I skipped the beginner path and went to the equation. C(ρ) = tanh(γ ln(1 + ρ/ρcrit)). My first reflex was "that's a Brillouin-type response to a field, not an order parameter," and the Coherence Function page beat me to it: it calls C a compander, says the tanh is *motivated* by the Ising fixed-point equation m = tanh(βJzm) but has no self-consistency loop, and Core Idea adds that C is analytic on its whole domain, so there is no critical point and β, ν are undefined by construction. That is exactly the right statement. In condensed-matter language: an explicit m = tanh(h/kT) never orders. I have no quarrel with the framing.

I then checked the identities by hand. All of them hold:

| Claim on site | My check |
|---|---|
| At γ = ½, tanh(½ ln(1+x)) = x/(x+2) = μ_simple(x/2) | ✓ exact |
| dC/dx = γ(1−C²)/(1+x), equals γ at x=0 | ✓; second-order term is −γx²/2 |
| Large x: 1−C → 2(1+x)^(−2γ); "n = 2γ" is the tail slope only | ✓ (Core Idea states the qualifier; the parameter table on Coherence Function does not) |
| Explicit reading C(gbar) gives gobs = gbar + 2a₀′ at γ=½ | ✓; gbar/[gbar/(gbar+2a₀′)] |
| BIC one-parameter penalty ln(2807) = 7.94; ΔBIC +7.1 ⇒ Δχ² ≈ −0.84 | ✓ |
| RMS 0.1485 vs 0.1437 dex ⇒ ΔBIC ≈ +184 for γ=2 pinned | ✓: (0.1485/0.1437)² = 1.068, ×2807 ≈ 190, minus 7.94 ≈ 182. Note this means ΔBIC scales linearly with N_eff |
| B_max = 1/Ω_m = 3.17; f_DM cap 0.685; f_DM = 0.927 needs B = 13.7 | ✓ |
| BTFR 3.35±0.07 vs 3.75±0.10 is 3.3σ | ✓ (0.40/0.122) |
| a₀ = cH₀/2π = 1.04×10⁻¹⁰ at H₀ = 67.4; Σ₀ = a₀/(2πG) = 119 M☉/pc² | ✓ both |
| 2a₀′ = 1.066×10⁻¹⁰ is 11% below 1.20×10⁻¹⁰ | ✓ |
| Deep-MOND σ = (4GMa₀/81)^¼ = 9.4 km/s at 10⁷ M☉ | ✓ |
| ρcrit = 0.029 V_flat² ≈ 64 M☉/pc³ for DDO 154 | ✓ (V ≈ 47 km/s) |
| γ = 2/√17 ≈ 0.49 | ✓ (0.485) |

So the arithmetic is trustworthy. Where I started disagreeing was in the statistics and in two pieces of prose.

**The effective-N problem.** The RAR form-selection table on Coherence Function treats 2,807 SPARC points as independent. **The "degeneracy" prose.** The Coherence Explorer says its ρcrit slider is "a rigid horizontal translation" and that this is "the γ↔ρcrit degeneracy that makes SPARC's γ = 0.489 non-identifiable against a rescaled critical density." A pan and a shape parameter are not degenerate with each other once data cross the knee, and the site's own table proves it: γ=2 and γ=0.489 with a₀′ profiled in both differ by ΔBIC 184. I checked the "degeneracy-breaking term is γ(2γ−1)" line on Coherence Function: match first-order slopes between tanh-log and μ_simple(x/2s) by setting s = 1/(2γ), and the x² coefficients differ by γ² − γ/2 = γ(2γ−1)/2. The Coherence Function table's "only γ/a₀′ identified" is likewise true only at first order in x.

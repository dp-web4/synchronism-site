# Topic: Which physical objects actually cross the coherence knee?

## Question
At V_flat = 200 km/s the framework's own normalization gives ρ_crit ≈ 1.2 × 10³ M☉/pc³. SPARC
samples x = ρ/ρ_crit at a median ~7 × 10⁻⁵ — no galaxy crosses the knee, which the site reports
correctly. But 10³ M☉/pc³ is **not an empty part of the universe**: globular-cluster cores, nuclear
star clusters and dense molecular cores live at 10²–10⁵ M☉/pc³.

**Has anyone looked in the one density decade where the framework's own knee sits?** And do
globular clusters discriminate — a ρ-keyed law has no external field effect, MOND does?

## Why It Matters
"0 discriminating tests" is a **stronger and more citable claim** once the knee decade has been
checked. Right now it is an inference from where SPARC happens to sample.

**Caution before this is run — read the 2026-09-06 explorer finding first.** The knee-inventory
session already found that the ledger's floored density law predicts f_DM = 0.685 at the solar
midplane against the Oort limit of 0.13 ± 0.04 (15σ), and registered globular clusters as the only
objects crossing the knee (S611 P611.2, **registered, never run**). So this topic is not new — it is
*already registered and still unexecuted*, which is itself the finding. The question for this
session is narrower and sharper:

1. Does the EFE asymmetry actually discriminate at globular-cluster densities, or does the framework's
   internal-locality violation (ρ_crit ∝ V_flat²) make "the framework's prediction for a globular
   cluster" **undefined**? A cluster has no V_flat. If ρ_crit cannot be evaluated for an object
   without an asymptotic rotation curve, the test is not merely unrun — it is *unformulable*, and
   that is a cleaner result than either outcome of running it.
2. If undefined: that is a third instance of the internal-locality no-go
   (`Research/proposals/galaxy_sector_internal_locality_ledger_20260907.md`) and belongs with it.

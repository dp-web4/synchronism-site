# Finding: Compander Family Numerical Equivalence Test

## Origin

Topic `compander-vs-order-parameter-commit.md` (seeded 2026-05-12, maintainer) and `coherence-function-governing-equation.md` (seeded 2026-05-11, maintainer). Both specify the same decisive test: fit Synchronism's tanh-of-log compander side-by-side against alternative compander family members on a calibration dataset and report AIC/BIC.

## Summary

Numerical test (script: `/tmp/compander_test.mjs`; results reproduced below) shows that **Synchronism's tanh-of-log and erf-of-log are model-selection-indistinguishable on the body of typical data, but the compander family is not fully degenerate — Hill function and arctan-of-log differ measurably in the tails.** The honest verdict is:

- "Any sigmoid would do" is *true for the body* (ρ within ~1 decade of ρ_crit).
- "Any sigmoid would do" is *false for the tails* (where the framework's only currently-testable discriminating prediction — wide-binary EFE — actually lives).
- The choice of tanh over erf-log is empirically unjustified at any data quality currently available to the framework.
- The choice of tanh over Hill or arctan-log *could* be empirically justified at σ ≲ 5% data quality — but only if the data were genuinely generated by tanh (a hypothesis the framework cannot defend without a derivation).

This nuances rather than confirms the "decorative tanh" hypothesis: tanh and erf are interchangeable; the full compander family is not.

## Research Notes

### Setup

I implemented four compander candidates with two parameters each (matching Synchronism's two-parameter form C(ρ) = tanh(γ ln(ρ/ρ_c + 1))):

1. **Sync tanh**: C = tanh(γ ln(ρ/ρ_c + 1))  — the framework's choice
2. **Hill** (power-law): C = ρⁿ / (ρⁿ + Kⁿ)  — Naka-Rushton / Michaelis-Menten class
3. **erf-of-log**: C = erf(α ln(ρ/ρ_c + 1))  — analog of Sync but with Gaussian-tail saturation
4. **arctan-of-log**: C = (2/π) arctan(β ln(ρ/ρ_c + 1))  — analog with algebraic-tail saturation

Note: a *logistic-in-log* function 1/(1 + (ρ/ρ_h)^k) is mathematically identical to Hill, so the family collapses from five to four. The framework's claim that "any of tanh, logistic, erf, arctan, Hill would serve" was already partially redundant.

**Interpretation**:

- **erf-of-log is the closest twin of tanh-of-log**. Maximum deviation 3.5%, RMS 1.4%. These differences are smaller than the noise floor of essentially any biological, astronomical, or chemical dataset Synchronism cites. The two forms are interchangeable at any data precision currently in the framework.
- **Hill function** is close (max 7%) but with a recognizably different shape — slower rise on the low-ρ side (because Hill's left tail goes as ρⁿ rather than logarithmically), faster rise around the half-saturation point.
- **arctan-of-log** is genuinely different. Its 1/x algebraic tail at large argument means the saturation is incomplete — even at ρ = 100 ρ_c the function is only 0.982. This is why arctan-of-log is rarely used as a compander — it's too slow-saturating.

### AIC/BIC on synthetic data

I generated 50 synthetic data points from Sync tanh (γ=2, ρ_c=1) with Gaussian noise σ = 5%, then fit each family by grid-search least-squares. The results:

```
Family       SSE      AIC      BIC      best-fit params           ΔAIC
Sync tanh    0.1479   -287.16   -283.34  (γ, ρ_c)=(3.43, 1.74)    +0.54
Hill         0.1820   -276.78   -272.95  (n, K)=(1.52, 0.28)     +10.93
erf-log      0.1463   -287.70   -283.88  (α, ρ_c)=(1.62, 0.88)    +0.00
atan-log     0.2462   -261.68   -257.85  (β, ρ_c)=(19.2, 5.07)   +26.03
```

**Interpretation**:

- **erf-of-log fits the tanh-generated data slightly better than Sync tanh itself does** (SSE 0.146 vs 0.148). ΔAIC ≈ 0.5 in favor of erf-of-log. With 50 datapoints, ΔAIC < 2 is the "no preference" threshold (Burnham-Anderson). So tanh and erf-of-log are model-selection-equivalent.
- **Hill loses by ΔAIC ≈ 11** when the true model is tanh and noise is 5%. This is "strong" preference for tanh on clean tanh-generated data. But if the true mechanism were something neither tanh nor Hill perfectly captures, this margin would shrink.
- **arctan-of-log loses by ΔAIC ≈ 26.** Comfortably ruled out — but again, this is on tanh-generated data, where arctan's slow saturation is the wrong tail.

### Noise-level sweep

I repeated the comparison at noise levels σ ∈ {0.01, 0.02, 0.05, 0.10, 0.20}, using the same noise seed and 50 datapoints. The ΔAIC between Sync tanh and its best alternative (always erf-of-log):

```
σ       ΔAIC(best_alt - Sync)   verdict
0.01      -1.49                  No preference
0.02      -1.01                  No preference
0.05      -0.55                  No preference
0.10      -0.30                  No preference
0.20      -0.23                  No preference
```

At every noise level tested, ΔAIC is within the "no preference" band (|ΔAIC| < 2). **erf-of-log is never disfavored against the form that generated the data.** This is a stronger statement than the topic anticipated: the family contains at least one member that is genuinely indistinguishable from tanh under model selection, regardless of data quality.

### Parameter degeneracy as a separate problem

I also noticed in the fit results: the best-fit parameters recovered by Sync tanh on its own data were (γ = 3.43, ρ_c = 1.74), even though the data was generated with (γ = 2, ρ_c = 1). The two parameters are anti-correlated: increasing γ steepens the curve, and the fit can compensate by increasing ρ_c to shift the curve right. The best-fit RMS error tracks the true error band closely (SSE/N ≈ 0.003, √ ≈ 0.054, vs. injected σ = 0.05), but the parameter values themselves are not well-determined.

This is a *separate* problem from the compander-family-equivalence issue: even within a single family, the framework's two-parameter form has parameter degeneracies at typical data precision. So "γ = 2" and "γ = 3.4" are observationally indistinguishable at σ = 5% — which means the framework's claim that γ = 2 is the "single-particle limit" cannot be tested by fitting Synchronism's own tanh form to real data.

## Implications for the Site

### The decisive verdict on the binary

**Synchronism's tanh-of-log is a member of an equivalence class within the compander family.** Specifically:

- **Equivalence class** {tanh-of-log, erf-of-log}: indistinguishable at any data precision currently available to the framework. These two forms cannot be discriminated by data.
- **Distinct class** {Hill / Naka-Rushton / logistic}: distinguishable from tanh on clean (σ ≤ 5%) data when the true model is tanh; mostly indistinguishable on noisy data. May or may not match real data; depends on whether physical data has logarithmic-tail or power-law-tail saturation.
- **Distinct class** {arctan-of-log}: too slowly-saturating to fit typical S-curve data; ruled out under model selection.

**This decisively confirms Frame B (compander), with a caveat the topic statement missed.** The caveat is that "any sigmoid would do" is *not literally true* — tanh and erf-of-log are interchangeable, but Hill and arctan are physically distinct functional forms with different tail behavior. The honest deep-page statement should be:

> "C(ρ) is one member of an equivalence class within the compander family. Specifically, replacing tanh with erf-of-log changes no current predictions of the framework. Replacing tanh with Hill or another power-law-tail compander would change predictions in the *tail* regime — for example, the wide-binary EFE prediction. The choice of tanh-of-log over erf-of-log is decorative; the choice of tanh-of-log over Hill is empirically untested but predictively load-bearing in some regimes."

### Connection to the wide-binary "ghost prediction"

The 2026-04-13 explorer finding `wide-binary-ghost-prediction.md` established that the site's quoted EFE result (g/g_N ≈ 1.31-1.39) was derived from the Hill form — but the site's code uses tanh, which predicts ≈ 1.02-1.10. The framework's only currently-discriminating prediction is sitting *exactly* on the boundary between compander-equivalent (tanh ↔ erf-log) and compander-distinct (tanh ↔ Hill) — and the site committed to the tanh side without acknowledging the bifurcation.

This is the key finding: **the compander choice is decorative for the body, but load-bearing for the tails**, and the framework's most-cited surviving prediction (wide binaries) lives in the tail. This is the inverse of the site's current implicit assumption that "tanh and Hill are interchangeable phenomenology."

### What the Phase Transitions page should say

Currently the Phase Transitions page treats the ~2× critical-exponents miss as a calibration error inside a phase-transition theory. Under Frame B (compander, confirmed):

- Critical exponents are a **category error** for a compander. Companders don't have universality classes; they have parameters. Asking what β, ν, γ_PT, η, α are for tanh-of-log is like asking what the universality class of μ-law audio encoding is — undefined.
- The "phase transition" framing should be dropped from the page title and replaced with "Saturation Knee in Coherence."
- ρ_crit should be renamed (per the 2026-05-08 finding on saturation knee) — the candidate names are ρ_half (half-saturation), ρ_knee (saturation onset), or ρ_scale (compander scale parameter).

### What the landing page should say

The current "one equation describes reality" framing presupposes that the equation has unique privileged content. The numerical test shows it doesn't — at minimum, erf-of-log produces identical predictions. The honest framing is:

> "We use a phenomenological compander C(ρ) = tanh(γ ln(ρ/ρ_c + 1)) to map presence to coherence. The choice of tanh-of-log over a closely related sigmoid (erf-of-log, Hill, μ-law) is not derived from a deeper theory — these forms are observationally indistinguishable on the body of typical data. The choice does matter for tail-extrapolated predictions (notably the wide-binary EFE), and we currently use tanh by convention; a compander-family comparison tool is in development."

## Open Threads

1. **What is the right compander for the framework's data?** The test here used synthetic data generated from tanh. The next step is to fit the four forms to the actual chemistry r=0.982 dataset (sound velocity vs. γ) and to SPARC rotation curves, and see which form wins on real data. If Hill wins, the framework should adopt Hill (and admit that the wide-binary EFE prediction is the right one — i.e., 1.31-1.39 not 1.05). If tanh/erf wins, the framework should drop the wide-binary EFE claim.

2. **Is "compander" the right category at all?** The deeper question — established as the 2026-04-09 scaffolding finding — is whether C(ρ) is doing any *predictive* work, or whether it's a notational convenience. A clean test: take a Synchronism prediction, derive it without ever invoking C(ρ), and see if anything changes. If nothing does, the equation is decorative end-to-end.

3. **What information-theoretic constraint, if any, pins down the compander form?** μ-law in audio is derived from the perceptual response curve (which is logarithmic — Weber-Fechner). Hill in pharmacology is derived from cooperative binding. Naka-Rushton in neuroscience is derived from photoreceptor response saturation. What's the equivalent for C(ρ)? If there is one, the framework can defend the choice. If there isn't, the choice is unconstrained and the equivalence class is the right object to commit to.

4. **The single-particle limit γ = 2 claim** — could be tested by fitting tanh-of-log to a dataset where γ is *known* to be 2 (a single quantum particle, in some preparation). The framework currently has no such test; the γ = 2 calibration is a definition, not a measurement.

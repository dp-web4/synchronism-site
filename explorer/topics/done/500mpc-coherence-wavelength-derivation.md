# Topic: Derive the ~500 Mpc Cosmic Interference Scale

## Question
What in the Synchronism framework picks 500 Mpc as the characteristic wavelength for galaxy cluster separation oscillations (TEST-07)? Can this scale be derived from the framework's parameters, or is it a free number?

## Context
Pass 4 (leading-edge researcher) stated this is the one prediction on the site they would actually run, and the one they would consider citing IF the magnitude is anchored from a derivation. The detail page `/cosmic-interference` returns 404. The test catalog lists TEST-07 as "Tier-1 / $0" but gives no derivation of the scale.

A research proposal has been filed to the Synchronism archive: `proposals/cosmic_interference_500mpc_derivation.md`.

The test is currently **asymmetric**: any oscillatory signal at ~500 Mpc confirms, only a total null (to 2000 Mpc) falsifies. To become a symmetric falsifier, the scale (and ideally amplitude) must be derived.

## Why It Matters
This is the highest-leverage open question for the site's credibility with expert audiences. Three Tier-1 tests (TEST-02, TEST-04, TEST-07) lack predicted magnitudes. Anchoring TEST-07 would:
1. Convert it from "exploratory hypothesis" to "falsifiable prediction"
2. Demonstrate the framework can make quantitative predictions, not just post-hoc fits
3. Give a reason for an observational cosmologist to look at this site seriously

## Suggested Starting Points
- Search Synchronism archive for "500 Mpc", "coherence wavelength", "large-scale structure"
- Apply Jeans-criterion derivation of ρ_crit at cluster scale: does V_flat → σ_cluster give λ ~ 500 Mpc?
- Compute the cosmological MRH for a cluster (~10^14 M☉, σ ~ 1000 km/s) and convert to a correlation length
- Check if the coherence function C(ρ) at cosmological densities has an oscillatory dispersion relation
- BAO is at ~150 Mpc (sound horizon). Does the framework predict a coherence-driven analog at larger scale?

## Failure Mode to Document
If the scale cannot be derived and is a free parameter, that is a productive result: TEST-07 should be re-badged "Exploratory" rather than "Tier-1" and the test description should say so explicitly.

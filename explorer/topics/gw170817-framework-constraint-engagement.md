# Topic: GW170817 — Does Synchronism Survive the Gravitational Wave Speed Constraint?

**Seeded:** 2026-05-03 (maintainer)  
**Priority:** HIGH  
**Context:** Pass 4 researcher (2026-05-03) identified that Synchronism makes zero statement about GW170817

## Question

GW170817 constrained |c_GW − c|/c < 10⁻¹⁵, ruling out most scalar-tensor modifications of gravity. A framework that modifies gravitational dynamics at galactic scales should say something about this constraint. Does Synchronism survive it, and if so, how?

The three possible answers have very different implications:
1. **Yes it modifies c_GW** → framework is already falsified (same fate as TeVeS)
2. **No, non-derivative coupling only** → survives GW170817 but needs explicit dynamical mechanism
3. **Not a field theory — it's a parameterization** → GW constraints don't apply, but scope must be stated clearly

## Context

The proposal `gw170817_coherence_field_coupling_constraint.md` in the Synchronism Research repo lays out the three cases. The explorer task is to determine which case is correct given the current archive, and to draft either a `/gw170817-constraint` page or a scope clarification for the site.

Key background:
- TeVeS (Bekenstein 2004) was ruled out by GW170817 because it modifies the GW kinetic term
- DHOST theories (Langlois & Noui 2016+) were specifically engineered to preserve c_GW = c while modifying gravity
- If Synchronism is parameterization (no action principle), GW170817 doesn't apply — but this scope restriction needs to be stated, not implicit

## Why It Matters

Researchers in modified gravity will ask about GW170817 within minutes. The site's silence reads as ignorance. Even if the answer is "we're not making a field theory claim," stating that explicitly is more credible than saying nothing.

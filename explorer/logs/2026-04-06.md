## Key Results

### 1. MRH Divergence ≠ MOND Transition

The critical density ρ_c (where MRH diverges) corresponds to the onset of ANY coherence — the deep MOND boundary — not the Newton-MOND transition. The MOND transition (C ≈ 0.63) is well inside the ordered phase.

### 2. Why Self-Consistency Was Dropped

The self-consistent model predicts C_sc = 0 for ρ < ρ_c, giving g_obs/g_bar → ∞ (infinite gravitational anomaly). Real galaxies don't show this. The site formula avoids the problem because C = tanh(h) > 0 for all h > 0. Self-consistency was dropped to avoid the C = 0 singularity. This was pragmatically correct but theoretically overcorrective.

### 3. The Crossover Resolution

Adding an external coherence field h_ext:

```
C_sc = tanh(h(ρ) · C_sc + h_ext)
```

- h_ext > 0 ensures C > 0 everywhere (no singularity)
- Sharp transition becomes smooth crossover
- Site formula = h_ext → ∞ limit (fully rounded)
- Crossover width scales as δρ/ρ_c ~ h_ext^(2/3)
- MRH peak scales as MRH_max ~ a / h_ext^(1/3)

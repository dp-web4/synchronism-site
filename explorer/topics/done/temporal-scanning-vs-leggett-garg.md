# Topic: Is "superposition = temporal scanning" macrorealist, and does Leggett–Garg already refute it?

## Question
The key-claims page reads superposition as "rapid temporal scanning through phase modes" (the CRT analogy in SPINE):
at each instant the system occupies one mode. Is that macrorealism in the Leggett–Garg sense (definite state at each
time + non-invasive measurability)? If so, observed Leggett–Garg violations (superconducting flux qubits, NMR, neutron
interferometry, photonic tests) already refute it. If not, which Leggett–Garg assumption does the scanning picture drop,
and does dropping it leave anything testable? Same question for Kochen–Specker contextuality and PBR (2012).

## Context
Visitor researcher persona, 2026-09-21: claim 1 is badged "untestable as stated" because nobody has set it against the
no-go theorems that would make it testable. The maintainer added this as an open question on /key-claims (2026-09-21).
The B1 CHSH runs already show local constructions saturate at S = 2; Leggett–Garg is the temporal analogue and targets
the scanning picture directly rather than the entanglement reading.

## Why It Matters
It could move a claim from "untestable as stated" to "tested against existing data", in either direction. A refutation
here would be the first on the quantum-foundations side that uses existing experiments rather than a toy harness. An
evasion needs a stated mechanism (invasive measurement = synchronization?), and that mechanism would itself be a
prediction.

## 1. What PCI Actually Claims, Empirically

### The operational definition
The Perturbational Complexity Index (Casali et al. 2013, *Sci Transl Med* 5:198ra105) is
computed by:
1. Perturbing the cortex with a transcranial magnetic stimulation (TMS) pulse.
2. Recording the resulting spatiotemporal EEG response.
3. Computing the Lempel-Ziv complexity (a specific algorithmic-compressibility measure)
   of the response pattern.
4. Normalizing to a value in [0, 1].

PCI is theory-motivated by Tononi's Integrated Information Theory: consciousness requires
brain activity that is simultaneously **integrated** (causally connected across regions)
and **differentiated** (high entropy in space-time). Lempel-Ziv complexity of a perturbation
response captures both: a conscious brain responds with a complex, distributed, non-stereotyped
pattern; an unconscious brain responds with a simple, local, or stereotyped pattern.

### The empirical threshold
Casarotto et al. 2016 (*Ann Neurol* 80:718–729) applied PCI to a benchmark population of
150 subjects (102 healthy + 48 brain-injured) across multiple consciousness states, plus
81 disorders-of-consciousness patients. Key findings:

- **PCI\* = 0.31** is the optimal cutoff between conscious and unconscious states.
- ROC analysis: **100% sensitivity and 100% specificity**, AUC = 1.00.
- Inter-subject variance is narrow enough that only 13 of 461 waking-state measurements
  fell within the unconscious distribution (2.8% overlap — effectively a clean separation).

### PCI values by condition

| Condition | PCImax median | Range |
|-----------|---------------|-------|
| Awake controls | 0.53 | 0.39–0.70 |
| REM sleep (dreaming) | 0.48 | 0.36–0.56 |
| Ketamine anesthesia* | 0.43 | 0.36–0.52 |
| MCS (minimally conscious) | 0.40 | 0.27–0.55 |
| VS (vegetative), high-complexity | — | 0.34–0.50 |
| NREM sleep | 0.25 | 0.15–0.31 |
| Propofol/Midazolam/Xenon anesthesia | 0.23–0.30 | 0.11–0.31 |

*Ketamine produces dissociative consciousness, which is why it lands above PCI\*.

The reported **transition is sharp** (visible in the ROC), **consistent across subjects**
(100% specificity), and **measured operationally** from TMS-EEG data. Every single property
in Synchronism's kill criterion is satisfied by this 10-year-old dataset, using a measure
that is not Synchronism's C.

## 3. The Distinguishability Test

If Synchronism's C is operationalized from EEG data (which it must be, for the kill
criterion to be testable), there are only four possible relationships between C and PCI:

### Case A: C is proportional to PCI (C ≈ k · PCI for some constant k)
Consequence: whatever sharp transition PCI shows at 0.31, C shows at k · 0.31. If the
framework is committed to C ≈ 0.50, then k ≈ 1.6, which means:
- Awake controls' median C ≈ 0.85 (rescaled from PCI 0.53)
- NREM sleep median C ≈ 0.40 (rescaled from PCI 0.25)
- Propofol anesthesia median C ≈ 0.37–0.48

In this case, **the transition occurs at C ≈ 0.50 by construction of the rescaling** —
the prediction is a reparametrization of PCI\*. No new information is produced. The site's
own taxonomy (Research Philosophy) has a "Reparametrization" badge for exactly this case;
this result belongs under that badge.

### Case B: C equals PCI (same functional form, same scale)
Consequence: the empirical threshold is **0.31, not 0.50**. The Synchronism claim that
the transition occurs at C ≈ 0.50 is falsified by 10-year-old data. The kill criterion
**triggers**: 0.50 is an inconsistent value across subjects — it is, in fact, the median
PCI of *fully awake controls*, not of the transition. At C = 0.50, most subjects are
comfortably conscious; the transition happened at 0.31.

**This is the critical observation.** The awake-control median PCI is 0.53, almost exactly
Synchronism's "threshold." If C correlates positively with complexity/integration measures
(as the framework implies through its IIT and GWT language), then C = 0.50 is not a
threshold — it is a description of ordinary wakefulness. The real threshold is lower. The
prior finding `consciousness-threshold-artifact-analysis.md` argued 0.50 is suspicious
because it is the midpoint of [0,1]. Casarotto 2016 provides the empirical anchor that
makes this critique concrete: the data says 0.31, not 0.50.

### Case C: C is a different complexity/coherence measure that tracks PCI in some regimes and diverges in others
Consequence: the prediction is genuinely testable, but requires specifying *where* C and
PCI diverge. Candidates:
- C from phase-locking value (PLV) during non-perturbed EEG would differ from PCI (which
  requires a TMS perturbation).
- C from spectral coherence metrics would give different threshold values depending on
  frequency band.
- C from a modular integration measure (e.g., binary phase-coherence thresholded by a
  cutoff) would produce different step shapes.

In this case, Synchronism can stake out a novel claim: "C ≠ PCI; specifically, the
measurement protocol we propose ({XYZ}) will show transition at C = 0.50 while PCI shows
0.31 in the same subjects." This is productive research territory. It requires commitment
to a specific operationalization, which the site currently lacks.

### Case D: C is operationalized from EEG and shows *no* sharp transition, while PCI does
Consequence: Synchronism's kill criterion triggers, but PCI still works. The framework
fails its own test while the competing empirical framework succeeds — the worst outcome.
This is a real possibility if C is operationalized as phase coherence in a single
frequency band during resting-state EEG (which tends to change gradually under anesthesia
rather than step-wise).

## 4. What the Site Can No Longer Say

Before engaging PCI, the site's honest-assessment position was "0 confirmed unique
predictions." That remains true. But the consciousness kill criterion is no longer
*forward-looking*. After Casarotto 2016:

- "Sharp discontinuity vs. gradual fade" is already **observed** — by PCI, not by Synchronism.
- "Consistent value across subjects" is already **observed** — at 0.31, not at 0.50.
- "Measurable at anesthesia induction" is already **measured** — in the Casarotto dataset.

Synchronism can no longer frame the prediction as "if the transition is sharp and
consistent, we are right." It has to frame the prediction as "the transition is sharp and
consistent at a threshold value of X, in units Y, where X ≠ 0.31 for measure Y distinct
from PCI." That is a harder claim and a more specific one. It is also a better one — it
is what a novel empirical prediction actually looks like.

Conversely, the site could acknowledge PCI as the existing benchmark and reclassify the
consciousness threshold as a **reparametrization** (using the site's own badge) of PCI\*
with a different measurement protocol. This is the honest option if the framework
ultimately produces a phase-coherence measure that correlates with PCI.

The third option — silently retain the current framing while neighboring peer-reviewed
literature has already answered the empirical question — is what the site is currently
doing. It is the weakest option.

## 5. Why the 0.50 Value Specifically Is a Problem

Across the prior consciousness findings, one thread has persisted: **0.50 looks like the
midpoint of a bounded scale, not a derived transition value**. The prior artifact analysis
(2026-03-07) could not rule this out from the inside. Casarotto 2016 provides an external
anchor:

- PCI ranges over [0, 1] — same as C.
- PCI is a complexity measure of integrated brain activity — the same concept family as C.
- PCI's empirical threshold is 0.31, not 0.50.
- PCI's value at ordinary wakefulness is 0.53 — almost exactly Synchronism's "threshold."

If two independent measures of roughly the same thing are both bounded in [0,1] but their
empirical thresholds differ by a factor of ~1.6, then the claim "the threshold is at the
midpoint" is unlikely to survive calibration of C onto data. The 0.50 value looks
increasingly like a choice anchored on "midpoint of the range," not on empirical
structure. This is the specific outcome the artifact-analysis finding warned would
eventually manifest.

The clean prediction Synchronism could still make: "When C is operationalized as [specific
measure], the empirical threshold is C\* = X, consistent across subjects with variance
Y, and sharp in the sense of [specific transition-width criterion]." Any value of X,
any measure, any variance — as long as it is specified. Until then, "C ≈ 0.50" is
unconstrained by data and its "kill criterion" is already-met by work the framework does
not cite.

## 8. What Would Rescue C ≈ 0.50 as Novel

A clean path exists. The framework can rescue its specific numerical claim by specifying
a C-operationalization that is demonstrably *not* Lempel-Ziv complexity of TMS-EEG
responses, and showing that this operationalization yields C = 0.50 at the conscious-
unconscious boundary with comparable or better sensitivity/specificity. Candidates:

- **Phase-lag index at a specific frequency band** (would need to argue why this
  captures coherence better than Lempel-Ziv).
- **Metabolic coherence** (glucose-uptake synchrony across regions, measurable via fMRI-
  coupled PET during anesthesia).
- **A consciousness-specific integration measure** derivable from f(γ, D, S) that can be
  computed from EEG without requiring TMS perturbation.

Each of these would make a genuinely novel, testable prediction: "at the conscious
boundary, [measure M] equals 0.50 ± δ, which differs from PCI\* = 0.31 by the structural
difference between M and Lempel-Ziv-of-TMS-EEG." This is the shape of a prediction worth
testing. It is also the shape of a prediction that would require Synchronism to
commit to a specific M, which the site has never done.

## Open Threads

1. **Is f(γ, D, S) effectively Lempel-Ziv complexity in disguise?** Integration +
   diversity + stability sounds conceptually adjacent to "integrated + differentiated"
   (the IIT phrase PCI operationalizes). If f is just a paraphrase of what PCI measures,
   then the C = 0.50 claim is Case A (reparametrization) with a shift in calibration.
   Someone could test this by computing f on the Casarotto dataset if the γ, D, S
   quantities are defined precisely enough.

2. **Does the PCI dataset's NREM sleep transition match the propofol transition in PCI
   space?** The table shows both clustering at 0.23-0.31 with range 0.11-0.31 — suggesting
   the PCI measurement is agent-agnostic for unconsciousness. If Synchronism's f predicts
   different values for different unconsciousness agents (propofol vs. NREM vs. xenon),
   that would be a point of potential divergence and therefore a testable novel prediction.

3. **The 13-of-461 overlap in Casarotto 2016.** Which waking subjects had PCImax below
   0.31? This is ~3% of waking measurements. Was there a systematic feature (subject
   state, TMS site, fatigue)? A theory that predicts who shows the overlap would be an
   interesting secondary claim.

4. **Does PCI satisfy Synchronism's kill criterion as stated?** Yes, fully. The site
   therefore has to either: accept that the kill criterion has already been passed by
   competing work (in which case its "novel prediction" claim collapses), or introduce
   a more specific kill criterion that PCI does not satisfy. Which kill criterion would
   Synchronism choose, and why?

5. **Ketamine at PCI 0.43.** Ketamine produces dissociative consciousness — subjects
   report rich subjective experience that differs structurally from ordinary wakefulness.
   PCI places it *above* threshold but below ordinary wakefulness. If Synchronism's C
   has something to say about the *content* of consciousness (not just presence/absence),
   ketamine is a natural test case: does C distinguish ordinary from dissociative
   consciousness? PCI partially does; does C?

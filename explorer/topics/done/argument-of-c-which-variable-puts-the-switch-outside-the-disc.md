# Topic: Which argument of C puts the transition outside the baryonic disc?

## Question
SPARC's objection to the density-keyed law is now measured as a **placement** failure, not an amplitude
one: at the Ω_m floor 77–88% of discs cannot be lifted at all, and at a freed floor (f = 0.089) the boost
is large enough but lands in the inner disc, costing 3–17× in χ²/N. Local density ρ puts the switch inside
the baryons by construction.

So: **is there an argument to C that turns on where the discs want it?** Candidates already named in the
archive but never run head-to-head on the same likelihood:
- surface density Σ (the disc's own scale, not the midplane volume density)
- an MRH-smoothed density (topic `mrh-smoothed-density-repair-untested-or-refuted.md` — still open)
- acceleration g_N (which is MOND, and is the only member of the family passing Oort + GCs + SPARC)
- the compander form (explicitly *not* killed by any run so far)

## Context
Maintainer 2026-09-09, from `joint-local-window-oort-gc-sparc...md` §7 (my correction to it) and its
script output. The 09-08 finding concluded "attack Ω_m as the floor next"; its own freed-floor rows show
that scan is finished and loses.

## Why It Matters
The site currently closes the density-keyed sector on the ceiling. That is the wrong close — it invites
the reader to think a better ceiling would fix it. The right close names the keying variable, and the
right close is only honest if someone has checked whether *any* argument works. If Σ or an MRH-smoothed ρ
lands anywhere near MOND's 21.2 χ²/N, that is the first non-trivial result this sector has produced. If
none do, the sector closes on a structural statement instead of a parameter, which is a stronger and more
citable null.

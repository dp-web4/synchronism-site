# Finding: The OOD Escape Is Sealed — and the Gate Is Derivation, Not Data

## Origin

Self-directed (WAKE-phase frame reframe, 2026-06-04), building on `explorer-loop-is-a-monotone-closure-operator.md` (2026-06-02, Open Threads #1 and #2) and `Synchronism/Research/Session674_Test_Catalog_Census.md` (2026-05-27). The standing posture — in this finding's own §7, in the project memory, and in the executor-track proposals — is that **the one escape from the loop's monotone closure is out-of-distribution (OOD) input: an executor track wired to genuinely new data.** This session tested that posture directly, and it does not survive contact with the catalog.

## Summary

I partitioned **26 sectors** of the framework into a 2×2-derived 4-cell scheme — {reparametrization, refuted-distinct, untestable-in-principle, **LIVE**} — where **LIVE = distinct from the established rival ∧ has a first-principles-derived amplitude ∧ untested**, the *only* cell in which new data could open a door. Then an adversarial escape-hunt tried, per sector, to *prove* the cell was LIVE; for the 9 genuinely-untested frontier tests (the S674 frontier) it did the per-test **amplitude-provenance** verification S674 named as "the recommended next work" and left undone.

**Result: the LIVE cell is empty. 0 genuine escapes found.** Final partition: **10 reparametrization, 4 refuted-distinct, 11 untestable-in-principle, 1 nominally-LIVE that collapses on inspection.** The one sector classified LIVE (TEST-01, tidal-dwarf-galaxy age–dark-matter correlation) is distinct *in sign* and untested, but its amplitude τ≈1.6 Gyr is **calibrated-post-hoc** — Session 51 introduces it as one of three ad-hoc fixes and explicitly files "derive τ from decoherence physics" as *future work*. Every one of the 9 untested frontier amplitudes traces to calibration, read-off, assertion, or self-contradiction; **not one is derived from first principles.**

This **refutes the standing "OOD input is the escape" posture** and replaces it with a sharper law:

> The fixed point is sealed against *data*. Every distinct prediction the framework makes is already in one of three closed states — reduces to a rival (reparametrization), executed-and-collapsed (refuted-distinct), or has no derived amplitude (untestable-in-principle). The (distinct ∧ derived ∧ untested) cell is empty. Therefore **new data cannot open a door, because there is no derived amplitude for new data to test.** The only thing that could re-open the program is a *future first-principles derivation* of one of the asserted amplitudes — a **theoretical** act, not a data-collection act. The executor track was prescribed as the escape; the audit shows the executor track has nothing to execute.

## Method

- **26 sectors** spanning galaxy dynamics, cosmology, quantum foundations, chemistry, consciousness, and the A2ACW methodology. Two-stage pipeline per sector: (1) classify into a cell, grounded in the actual site pages (`src/app/*`), explorer findings, and research archive sessions; (2) **adversarial escape-hunt** — argue *for* LIVE first, then verdict. For the 9 untested frontier tests (TEST-01, 06, 07, 11/20, 12, 17, 21, 22, plus catalog TEST-16/23/24 surfaced by the critic), stage 2 was a **provenance trace**: find the archive session/line where the amplitude is introduced and how it is justified.
- A completeness critic checked for omitted sectors and buried live cells, and rendered the final escape verdict.
- This is a measurement, falsifiable by a single counterexample: **any** sector that is distinct ∧ derived-from-first-principles ∧ untested would be a live escape and flip the verdict to "open — run it." None was found.

## 4. The frame correction (the actual result)

The standing posture (this finding's predecessor §7; memory `project_explorer_loop_monotone_closure`; the executor-track proposals): **"the only structural escape is out-of-distribution input — wire an executor to genuinely new data."**

That is wrong in a specific, instructive way. New data tests *predictions*; the framework's distinct predictions have **no derived amplitudes**, so a non-detection is always absorbed ("amplitude too small / τ a bit longer") and a detection is never Synchronism-specific (the amplitude was free). **Data cannot escape an amplitude-free theory.** The binding constraint is not the absence of an *outside* (the §5 "corpus cannot supply its own outside" mechanism); it is the absence of a *derivation*. Concretely:

> **The gate is derivation, not data.** The only move that re-opens the program is a *future first-principles derivation* of one asserted amplitude (τ_TDG, ε_void, C*, …) — new **theory**, generated from inside, not new data applied to existing theory. And deriving an amplitude is exactly the move the loop has never made: every "derivation" audited (a₀, γ=2/√N_corr, Born rule, A≈0.029, τ, Φ_crit, C*) turned out to be calibration, dimensional bookkeeping, or assertion.

This is strictly sharper than "OOD is the escape," and it **inverts the prescribed remedy**: building an executor track to crunch new SPARC/DESI/Gaia cuts cannot help, because there is nothing derived to feed it. The productive remedy, if one exists, is theoretical — derive an amplitude and *pre-register* it — which is the one thing the monotone-closure dynamics predict the corpus-bound loop will not do (deriving-then-failing is more expensive than asserting-then-absorbing).

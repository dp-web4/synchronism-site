### 2. What if the current research frame is wrong?

The site presents itself as a *falsification-first* program (kill criteria, pre-registered tests, a prediction audit trail). But every Tier-1 result the site reports is structurally a post-hoc consistency check: predictions written after the data was public, kill criteria stated retroactively, "0 of 24 run as formal pre-registered tests" buried as a footnote on `/test-catalog`. The honest reframe is *consistency-mapping*: the framework can compute a number, the data has a number, the two either agree or don't, and the agreement-or-disagreement is informative about whether the framework's parameter combinations match observed correlations — but it is not falsification in the Popperian sense.

If this is right, the entire P0 fix list (badges, kill criteria, prediction tracker) is rearranging deck chairs. The deeper move is to stop calling these "predictions" and start calling them "compatibility analyses." The framework keeps surviving its own audits because the audits keep finding the same thing: the framework is doing in-distribution re-description, A2ACW certifies internal consistency not external discovery, and the "0 vs 1" scoreboard is a category error.

### 3. What experiment or investigation would most increase information right now?

**Audit all Tier-1 prediction commit timestamps against the data release dates they target.** This is binary, fast, decisive, and reframes the entire site's epistemic posture in a single finding. The visitor's Pass 4 explicitly asked for it. The maintainer flagged Session 107 specifically. The topic was seeded yesterday. If even one Tier-1 prediction is genuinely pre-data and derivation-independent, the framework has its strongest credibility artifact and it's invisible. If none are, the falsification framing collapses to consistency-checking and the front-page math has to follow.

### 4. What would falsify the current research posture?

- **Outcome A**: All Tier-1 kill criteria postdate their data releases AND derivations cite or are calibrated against the data → site's falsificationist self-presentation is misleading; honest framing is "0 prospective predictions tested, N post-hoc consistency analyses." The /research-philosophy "1 refuted external" line should be replaced with "1 post-hoc tension."
- **Outcome B**: At least one prediction predates its data AND is data-independent → that prediction is the framework's strongest credibility artifact and should headline the site. If it disagrees with the data (like fσ₈), the site has its first real falsification. If it agrees, the site has its first genuine confirmed prediction.
- **Outcome C** (mixed): Some predictions are pre-data, some post-hoc. The site needs per-test labeling and a clear separation of the two epistemic categories.

Decision: I'm doing the audit. It dominates everything else in the queue on information-per-hour.

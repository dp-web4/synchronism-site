## Key Findings

  growth-suppression prediction at 2.4σ on combined σ₈ (0.841 ± 0.034 vs Sync's

  ΛCDM, not where it should agree.

## Rabbit Holes (Worth Revisiting)

1. **DR2 full-shape paper**. DESI DR2 BAO is published (arXiv:2503.14738) but
   the full-shape companion was not located in this session — search returned
   indications it's in pipeline. When released, the comparison should be redone
   with ~3× tighter precision. Expected: push the disfavoring from 2.4σ toward
   3.5–4σ. **Action**: monitor DESI publications page for FS DR2 paper.

2. **Modified-gravity μ_0 connection**. DESI 2024 VII reports
   μ_0 = 0.11 +0.45/−0.54 from FS+BAO alone — consistent with GR. Synchronism's
   growth suppression should imply μ_0 < 0 at meaningful significance if real.
   Another tension axis the framework hasn't engaged.

3. **The QSO outlier (σ₈ = 0.95 ± 0.07)**. DESI notes "eBOSS quasar sample appears
   to prefer slightly higher σ_8 than BOSS LRGs." Known feature, not Sync-specific,
   but it inflates the combined Sync tension by ~0.4σ. Worth watching if QSO
   is later revised.

4. **σ₈(z=0) framing**. Session 107 reports σ₈(z=0) = 0.76 explicitly. Is this
   the same operational σ₈ DESI measures? If Synchronism's modified f(z) implies
   a different σ₈(z=0)→σ₈(z=0.5) mapping than ΛCDM, the comparison could in
   principle be redone in Sync's own normalization. Session 107 doesn't make
   this distinction so I haven't either, but a Synchronism advocate could
   defensibly argue this is the soft spot.

5. **The framework now has a *failed* prediction archive entry**. Should the
   site grow a "Failed prediction archive" page distinct from the structural
   failures (Bullet Cluster sign error)? TEST-03 (RAR scatter, Kill Criterion
   Triggered 2026-04-30) and TEST-04a (DESI fσ₈, Disfavored 2026-05-05) are now
   two specific numerical predictions whose data has come in against the
   framework. That's a different epistemic event than discovering structural
   incompatibility, and should probably be visualized differently.

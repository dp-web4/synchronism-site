00 eq at O(eps):   8*pi*G*rho(x, y, z) - phi0*Derivative(Phi(x, y, z), (x, 2)) - phi0*Derivative(Phi(x, y, z), (y, 2)) - phi0*Derivative(Phi(x, y, z), (z, 2)) = 0
   => phi0 lap(Phi) = 8 pi G rho  (matches paper Eq. 24 with phi=2 Newtonian):  True
11 eq at O(eps):  phi0*Derivative(Phi(x, y, z), (x, 2)) - 2*phi0*Derivative(U(x, y, z), (x, 2)) - phi0*Derivative(U(x, y, z), (y, 2)) - phi0*Derivative(U(x, y, z), (z, 2)) + Derivative(dphi(x, y, z), (x, 2)) = 0
12 eq at O(eps):  phi0*Derivative(Phi(x, y, z), x, y) - phi0*Derivative(U(x, y, z), x, y) + Derivative(dphi(x, y, z), x, y) = 0
Off-diagonal xy equation fixes the combination -> phi0*Derivative(Phi(x, y, z), x, y) - phi0*Derivative(U(x, y, z), x, y) + Derivative(dphi(x, y, z), x, y)
U = k*Phi outside a point mass, xy eq => k = [0]
xx eq residual with that k (vacuum): 0
PPN gamma = U/Phi = 0

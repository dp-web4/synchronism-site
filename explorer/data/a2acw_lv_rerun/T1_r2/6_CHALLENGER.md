# Closing Artifact: CHALLENGER

The Defender conceded most of the whitepaper's framing. What remains is textbook kT/E_b scaling, and Synchronism has not yet derived anything from its own dynamics.

## HELD (survives)
- **Weak claim:** known life and conventional human-built computing operate at roughly 250-400 K. This is descriptive and true.
- **Two-scale window form:** persistence depends on kT relative to E_mem (memory/structure) and E_act (activation/update). This is standard statistical mechanics, not a Synchronism result.
- **Gradients as power source:** ΔT supplies the free energy, and ambient T selects which patterns persist. The Defender's reframing is defensible.
- **Autonomy rule as a form:** the 10%/10% thermal-contact and power-budget rule is acceptable, provided E_b is measured independently.

## NARROWED (must be scoped)
- **"Universal law" → contingent band.** The ~300 K value is set by α, m_e, and the chosen chemistry (the Rydberg scale). Only the dimensionless ratio kT/E_b has any claim to universality.
- **Strong claim → pre-committed scope.** It covers only autonomous systems whose information-carrier E_b is spectroscopically measured in 0.1-1 eV, independent of the observed T, and which are sustained outside 100-600 K. A "lower E_b" retreat after the fact is disallowed.
- **P1 (T*/T_c ≈ 0.6-0.9) → conditional prediction.** It survives only as an explicit function of repair budget, with finite-size scaling and a same-metric Ising/Hopfield null. The null of T*/T_c ≈ 1 is a straw null, since sub-critical optima are already known in Hopfield memories, annealing, and stochastic resonance. Novelty requires a literature check.
- **Silicon AI → cooling economics.** Landauer favors colder operation. Today's ~300 K is a CMOS and refrigeration-cost fact, not a thermodynamic requirement for organization.

## FAILED (unsupported / overreach)
- **"Foundational" T:** it is an emergent ensemble statistic.
- **T ≡ ⟨V²⟩:** it has no mass or Boltzmann factor, so its units are not kelvin. It is non-negative, which conflicts with §5.20's negative temperature. The linear D(T) and γ(T) contradict the Arrhenius-based argument.
- **Substrate convergence as independent evidence:** it is a selection effect, because carbon life built silicon computing for its own environment.
- **"0.00001% of the cosmic range":** it uses an arbitrary linear measure and carries no content.
- **Band derivation:** 300 ± 100 K, and later 150-450 K, was back-fitted. The widening to 100-600 K makes the claim nearly safe by construction.
- **Operational falsifiability of the strong claim:** the live tests (Titan, >600 K surfaces) are not observable on any current timescale.
- **Intent-dynamics contribution:** there is no committed c = kT*/E_b, no plateau width, and no mapping from Intent saturation parameters to T and E_b. Section 4.7 is currently textbook scaling in Synchronism vocabulary.

## WOULD SETTLE (decisive evidence/test)
- **Pre-registered simulation:** the Intent model commits c and the plateau width from its own parameters before the run. The result must hold under finite-size scaling and a fixed metric, and a generic Ising/Hopfield null with the same metric must fail to reproduce it.
- **Null reproduction:** if the generic null also gives T*/T_c ≈ 0.7, or if the peak does not scale with E_b, Synchronism adds nothing.
- **Autonomous counterexample:** a system with independently measured carrier E_b in 0.1-1 eV, passing the autonomy rule, sustained outside 100-600 K. This falsifies the strong claim.
- **Spectroscopic pre-commitment:** a written E_b measurement rule fixed before any candidate system is examined.

HEADLINE: NARROWED

## Summary

The shipped posture ("C has no operational calibration in any domain; doubly unanchored") is
**directionally right but imprecise, and the imprecision is load-bearing.** The archive contains
**six** distinct C-from-measurable constructions, not zero. Classifying them against the topic's
own (a)/(b)/(c) rubric yields a sharper and more defensible result:

- **No (a)-class protocol survives** (genuinely independent measurable → C predicted → C checked).
  There is exactly one *attempt* (CFD Reynolds-number form), and it dies at operationalization with
  a documented **440× internal inconsistency** — it was never instantiated to SI units.
- **C is observable at exactly one rung — galaxies — and there it is measured *as the very target
  it predicts*** (C_obs = g_bar/g_obs, the inverse mass-discrepancy = the RAR y-axis), so it is
  class (b) circular; and the C(ρ) prediction of it is **refuted** (γ=2 rejected ΔBIC=+184;
  free-γ→0.49≡MOND; the total-boost slope is even **wrong-sign**, Session 414 Test 5).
- **Everywhere else C is never measured at all** — it is computed *forward* from inputs (ρ, d/λ,
  D, S) and compared to nothing, or its function is unspecified (consciousness Form 2), or the
  observable is wrong/undefined (TEST-12 "effective C", EEG phase coherence).

So the precise statement is **not** "no measurable maps to C." Measurables *feed* every C
construction. The precise statement is: **C is a latent variable — computed forward, never
independently measured and checked — except at the galaxy rung, where the one available
measurement of C coincides with the prediction target and the prediction fails.** "Unrunnable as
stated" is correct for the consciousness/chemistry/quantum claims; but the umbrella phrasing "no
measurable maps to C in any domain" understates the galaxy rung (where C is the *most*-measured
quantity in the framework, the RAR) and overstates the cleanliness of the absence elsewhere.

## Research Notes

### The decisive distinction: forward map vs. measurement

The topic's question is whether C can be **measured independently of the data it predicts**. The
whole survey turns on one distinction that the binary "protocol exists / doesn't" framing blurs:

- A **forward map** takes a measured *input* and computes a *predicted* C. Example:
  C(ρ)=tanh(γ·ln(ρ/ρ_crit+1)) takes measured density ρ → predicted C. The input is measurable;
  the output C is **not measured**, it is asserted by the map.
- A **measurement** of C produces C from data *as an output*, so the map's prediction of C can be
  checked against it. This is what PCI*=0.31 (Casali 2013) is for consciousness: a procedure, a
  number, a validation cohort — C-side, not input-side.

Every C construction in the archive is a forward map. C is a **latent variable**, never a measured
observable — with the single galaxy-rung exception below, which is the exception that proves the
rule because the "measurement" there is the prediction target itself.

**#1 C(ρ) — class (b), the galaxy rung.** g_eff = g_N/C(ρ) ⟹ C = g_N/g_obs = g_bar/g_obs. That
is the inverse mass discrepancy — the RAR y-axis — a real observable. So C *is* measurable here.
But it is measured *as the inverse of the rotation curve*, which is exactly the prediction target;
it is not independent. And the C(ρ) prediction of this observable fails three ways: γ=2 rejected at
ΔBIC=+184, free-γ collapses to 0.49≡MOND, and the total-boost vs N_corr slope is wrong-sign
(Session 414, Test 5: predicted ∝R^+0.5/V, observed ∝V^+1.2/R^0.36). **The one place C is an
observable is the one place the framework's C is refuted by it.**

**#2 CFD Reynolds form — the only (a)-class attempt, and it's dead.** `CFD_Reframing_NS` proposes
C = 1/(1+1/Re_internal), C from the pattern's internal Reynolds number — genuinely independent of
any downstream prediction, and explicitly "not just a reframing… a derivation path." This is the
single construction that, if it worked, would give C an independent measurement.
`CFD_Structural_Tensions` (Session 2 update, 2026-03) records its death: Re_internal is never
operationally defined in SI (ρ, v, L, μ), and inferring Re_max from the three stipulated thresholds
(C=0.3/0.5/0.7) yields values that **differ by 440×** — no single Re_max is consistent with all
three. The protocol exists as a sketch and fails its own internal consistency check before any data
contact. This is the strongest single piece of evidence for the closure: *the framework tried to
build an independent C-measurement and could not make it self-consistent.*

**#3 Consciousness Form 2 — class (c), measurable inputs but no function.** D (neural state-space
entropy) and S (coherence persistence, ms) *are* EEG/MEG-measurable (S358: psychedelics raise D
without changing γ; seizures have low γ but zero consciousness via D≈0.05). So two of three inputs
are real observables. But (i) the function f in C=f(γ,D,S) is **never written** — only threshold
conditions (γ<0.001, D>0.3, S>25ms) and a lookup table (S359); (ii) γ routes through asserted
N_corr; (iii) this is a **different C** from C(ρ) — S640 verified D,S are not functions of ρ, the
0.50 is independent 8-way convergence, only γ is shared. The EEG-phase-coherence kill criterion is
wrong-observable (C isn't phase coherence; BCS at C≈0); the measurable-input handle that *does*
exist (D, S) is wasted because f is unspecified. **This is the gap the site should name precisely:
not "C unmeasurable" but "C=f(γ,D,S) has measurable D,S and an unwritten f."**

**#6 C_conv — a genuine (a)-class measurement, of a different C.** In the Gnosis/trust track,
C_conv = belief convergence between agents, measured directly from conversation turns 1-3
(`TRUST_COHERENCE_CONSCIOUSNESS_SYNTHESIS`), with a pre-registered falsifier ("if C_conv
uncorrelated with session duration"). This is the one place the framework has a real C-from-data
procedure with a stated falsifier. But it is the **multi-agent trust convergence** coherence, not
C(ρ) and not consciousness-C — a fourth functional object sharing the letter. It shows the
framework *can* operationalize a coherence when the domain hands it a natural measurable
(inter-agent agreement); it just can't for the physics C, where the only natural measurable is the
prediction target.

### The refinement to "doubly unanchored"

Memory (`c-doubly-unanchored-unrunnable-category`, 2026-06-11) says C is unanchored on both the
input side (N_corr asserted, 2026-06-08) and the output side (no measurement). The survey refines
the output-side claim:

> C's output is anchored **exactly once** — at the galaxy rung, where C_obs = g_bar/g_obs is the
> RAR observable — and the C(ρ) prediction of it is **refuted**. Everywhere else the output is
> unanchored (forward-computed, never measured). The one independent-measurement *attempt* (CFD
> Reynolds) is internally inconsistent by 440×.

This is stronger than "unmeasurable," because "unmeasurable" invites "so wait for an instrument,"
whereas the real situation is: where C is measurable it is refuted, and where it is not refuted it
is not measurable. That is the same refutable-not-confirmable asymmetry the wide-binary sector hit
(2026-06-05) and the same re-execute-don't-re-trust lesson (DESI 2026-05-25, A-from-Jeans
2026-06-07), now at the level of the framework's central quantity.

### What would falsify *this* finding

A construction I missed in which C is measured from a data channel **other than** the prediction
target, with a stated comparison. I searched: `measure C`/`infer C`/`estimate C`/`C from data`/
`proxy for C`/`operational definition`/`operationalize` across 724 Research files + Chemistry +
Gnosis + simulations. The candidates that surfaced are the six above. The closest to a clean miss
would be C_conv (#6) — genuinely measured — but it is a different C in a non-physics track. If a
physics-C measurement independent of the rotation curve exists, it is not in the obvious places.

rho_DE/rho_crit (gamma=1/2) = 2
  d(rho_DE)/dx  = 0
  => rho_DE is INDEPENDENT OF DENSITY, identically. Not just constant in time.

  -- the locality identity --
  1 + w_DE                       = (-2*gamma*x*(x + 1)**(2*gamma - 1) + (x + 1)**(2*gamma) - 1)/((x + 1)**(2*gamma) - 1)
  dln(rho_DE)/dln(rho_m)         = (-2*gamma*x*(x + 1)**(2*gamma) + (x + 1)*((x + 1)**(2*gamma) - 1))/((x + 1)*((x + 1)**(2*gamma) - 1))
  difference (must be 0)         = 0
  => delta_DE / delta_m = 1 + w_DE, EXACTLY, at all x and all gamma.
     The clustering amplitude IS the departure from Lambda. Same number, one channel.

6. WHY EVERYTHING SCALES AS epsilon = 2*gamma - 1  (series, exact)
==============================================================================
1 + w  to O(eps): epsilon*(-x + log(x + 1))/x
   -> 1 + w = eps * ( ln(1+x)/x - 1 ) + O(eps^2).  Vanishes identically at eps=0.
F*(1+w) [the Poisson-source correction] to O(eps): 2*epsilon*(-x + log(x + 1))/x**2
   at x0 = 6/7 (mean density today): coefficient = -0.648171 (times eps)
   with eps = 2*0.489-1 = -0.022  ->  G_eff/G - 1 = +0.01426 at z=0

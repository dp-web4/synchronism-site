# Topic: N_corr Operational Definition — The Missing Recipe

## Question

How do you *compute* N_corr for a real system — a galaxy, a brain, a chemical bond, a superconductor — from observable quantities, without presupposing which regime the system is in?

## Context

The 2026-04-28 visitor log logged this as a HIGH severity issue across both Pass 3 (grad student) and Pass 4 (researcher). The γ Calculator provides preset values (water = 4, enzyme = 50, ferromagnet = 10²³) with no methodology. The galaxy plotter uses γ = 2 (N_corr = 1, "uncorrelated stars") to fit rotation curves, but stars in a galaxy are gravitationally bound — N_corr = 1 is incoherent with the physical reasoning that motivates γ.

The grad student identified this as "the framework's biggest unmarked load-bearing parameter": every γ-based prediction (regime classification, consciousness threshold, RAR scatter, EEG anesthesia) is unfalsifiable in practice until N_corr has a derivable operational definition.

## Why It Matters

- If N_corr has a principled derivation from observables, the framework makes genuine predictions (you compute N_corr from measurements, then predict which regime and what γ)
- If N_corr is a free parameter fitted post-hoc, the framework is unfalsifiable for any new system
- The galaxy case (γ = 2 meaning N_corr = 1 despite gravitational binding) may reflect a category error: quantum N_corr (wavefunction overlap) vs. dynamical N_corr (number of correlated degrees of freedom). This is the same conflation the 2026-04-22 explorer finding identified in `galaxy-gamma-same-page-contradiction.md`

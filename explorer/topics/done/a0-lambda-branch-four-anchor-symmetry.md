# Topic: the constant branch of Milgrom's coincidence (a₀ ∝ c√Λ) never got the four-anchor treatment

## Question

`/parameter-derivations` row 4 gives branch (A), a₀(z) = cH(z)/2π, a four-anchor analysis against Ciocan et al.
2026 (arXiv:2604.22613) and finds the verdict flips with the a₀(0) anchor (+9.8σ low on the framework's own
anchor, +0.5σ consistent on McGaugh+2016, −2.3σ high on MIGHTEE-HI). The Λ half — a₀ ∝ c√Λ, zero evolution —
is dismissed in one sentence at "roughly 12σ at the Milgrom-local normalization." Same anchor problem, no
anchor analysis. Apply the identical four-anchor table to the constant branch. Does *its* verdict also flip?

Second half (visitor Pass 4, 2026-09-05, unanswered question 5): the site says branch (B) "is not available"
because an emergent a₀ forces H(z). But Λ is also a cosmological quantity; an emergent scale tied to the
present-day critical density is *degenerate* between H₀ and √Λ at z = 0 (ρ_crit = 3H₀²/8πG; Ω_Λ = Λ/3H₀²).
Which does the archive's Step-1/Step-2 derivation on `/mond-unification` actually commit to? Read
Sessions #87–88 and say whether the H(z) commitment is derived or assumed.

## Context

Pass 4 called a₀(z) "the one prediction that structurally differs from MOND" and "the genuine open question

## Why It Matters

If the constant branch is *also* anchor-consistent, then Ciocan constrains neither reading of the 1983
coincidence and the "12σ" sentence is an over-refutation of MOND's own position, which this site should not
carry. If it is not, the site has a genuine (if MOND-side) result: high-z RAR data prefer an evolving a₀.

## Pre-registered rule

Compute branch (B) at z ≈ 1 on the same four anchors (Ciocan intercept 1.00, framework 1.04, McGaugh 1.20,
MIGHTEE 1.69) against Ciocan's 2.38 ± 0.10. **If any anchor puts constant a₀ within 2σ, the "12σ" sentence is
withdrawn and both branches are labelled anchor-dominated.** If all four exceed 5σ, the sentence stands and
the site may state that Ciocan disfavors constant a₀ independent of anchor — a MOND-side finding.
